### PLANNING

- **Webhook event schema.** Defined standardized webhook event payload schemas across packages/webhook-events.

### BACKEND

- **Event dispatcher.** Dispatches real-time webhook events (delivered, opened, clicked, bounced, spam_complaint).
- **HMAC verification.** Added HMAC-SHA256 signature headers on every outgoing webhook payload for tamper-proof verification.
