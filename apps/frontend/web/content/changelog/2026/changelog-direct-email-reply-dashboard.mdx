### FRONTEND

- **Reply composer.** Rich text and markdown composer built into the thread detail view in the dashboard.
- **Sender address selector.** Dropdown to pick from verified custom sending domains with SPF/DKIM alignment.

### BACKEND

- **Reply routing.** Outbound reply dispatch endpoint in apps/backend/inbox linking responses directly to conversation thread IDs.
