### PLANNING

- **ClickHouse logging.** Designed event schema for email delivery, bounces, opens, clicks, and complaints with 30-day retention TTL.

### DESIGN

- **Template editor layout.** Full-screen canvas, dark mode palette, breadcrumb header, floating preview panel, code view mode.

### FRONTEND

- **Visual template editor.** Drag-and-drop block builder, live HTML preview, variable insertion.
- **ClickHouse log viewer.** Search, filter by status, detail modal with raw MIME payload.

### BACKEND

- **ClickHouse ingestion pipeline.** High-throughput log writer for KumoMTA delivery events.
