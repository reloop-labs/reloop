### TOOLS & FEATURES

- **Temporary Email Checker.** Built a real-time email checker tool with score breakdowns, automated paste triggers, and instant REST API integration snippets.
- **Interactive Waste Calculator.** Introduced an interactive slider estimating monthly and yearly budget lost to fake and disposable email signups.
- **Email Validator UI refresh.** Enhanced email validator tool with keyboard shortcuts, avatar gradients, and detailed MX record inspection.

### DESIGN

- **Blueprint CAD artwork suite.** Created technical SVG blueprint graphics with squircles and CAD intersection ticks (`TempEmailTimerArt`, `BimiBlueprintArt`, `ValidatorArt`).
- **Monochrome dark mode.** Tuned tools interface to a clean monochrome dark theme with high-contrast badge indicators.
- **Custom typography & wordmark.** Standardized on Inter typography with custom gradient footer wordmarks and blueprint section frames.

### INFRASTRUCTURE & SEO

- **Single source of truth for pricing.** Extracted all pricing schemas, tiers, and limits into `@reloop/pricing` with CI drift enforcement.
- **SMTP relay boundary integrity.** Resolved MIME boundary corruption on boundaries ending in `=` within the SMTP relay engine.
- **Reverse proxy self-hosting.** Supported running the self-hosted installer behind existing reverse proxies including Traefik and Caddy.
- **Site-wide SEO audit.** Implemented canonical tags, structured JSON-LD schemas, automated sitemaps, and OpenGraph preview images.
- **Free tier domain limit.** Increased free tier custom domain limit from 1 to 3 domains.
