# Authentication Service

The Reloop Authentication Service provides comprehensive user authentication, authorization, and session management capabilities.

## Overview

- **Base URL:** `/api/auth`
- **Version:** v1
- **Authentication:** Bearer tokens, API keys, JWT
- **Rate Limits:** 1000 requests per minute per API key

## Quick Start

### 1. Get an API Key

First, you'll need an API key to access the service:

```bash
curl -X POST https://reloop.sh/api/auth/v1/api-key/create \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -d '{
    "name": "My API Key",
    "permissions": ["read", "write"]
  }'
```

### 2. Authenticate Requests

Use your API key in the Authorization header:

```bash
curl -X GET https://reloop.sh/api/auth/v1/users \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## API Endpoints

### Authentication
- `POST /api/auth/v1/sign-up/email` - Register new user
- `POST /api/auth/v1/sign-in/email` - Sign in with email
- `POST /api/auth/v1/sign-out` - Sign out user
- `POST /api/auth/v1/refresh-token` - Refresh access token

### User Management
- `GET /api/auth/v1/users` - List users (admin only)
- `POST /api/auth/v1/users` - Create user (admin only)
- `PUT /api/auth/v1/users/{id}` - Update user
- `DELETE /api/auth/v1/users/{id}` - Delete user (admin only)

### Session Management
- `GET /api/auth/v1/sessions` - List user sessions
- `POST /api/auth/v1/sessions/{id}/revoke` - Revoke session
- `POST /api/auth/v1/sessions/revoke-all` - Revoke all sessions

### API Key Management
- `POST /api/auth/v1/api-key/create` - Create API key
- `GET /api/auth/v1/api-key/list` - List API keys
- `PUT /api/auth/v1/api-key/{id}` - Update API key
- `DELETE /api/auth/v1/api-key/{id}` - Delete API key

## Error Codes

| Code | Description |
|------|-------------|
| 400 | Bad Request - Invalid input |
| 401 | Unauthorized - Invalid or missing authentication |
| 403 | Forbidden - Insufficient permissions |
| 404 | Not Found - Resource not found |
| 429 | Too Many Requests - Rate limit exceeded |
| 500 | Internal Server Error - Server error |
