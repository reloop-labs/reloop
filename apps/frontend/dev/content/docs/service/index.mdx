# API Services

Welcome to the Reloop API Services documentation. Here you'll find comprehensive documentation for all our microservices.

## Available Services

### Authentication Service
- **Base URL:** `/api/auth`
- **Description:** User authentication, authorization, and session management
- **Documentation:** [Auth Service](/service/auth)

### Mail Service
- **Base URL:** `/api/mail`
- **Description:** Email sending, templates, and delivery management
- **Documentation:** [Mail Service](/service/mail)

### Webhook Service
- **Base URL:** `/api/webhook`
- **Description:** Webhook management and event delivery
- **Documentation:** [Webhook Service](/service/webhook)

### Server Service
- **Base URL:** `/api/server`
- **Description:** Core server functionality and data management
- **Documentation:** [Server Service](/service/server)

## Getting Started

Each service provides its own API endpoints and documentation. Click on any service above to explore its specific endpoints, authentication methods, and usage examples.

## Authentication

Most services require authentication. See the [Auth Service](/service/auth) documentation for details on how to authenticate your requests.

## Rate Limits

Each service may have different rate limits. Check the individual service documentation for specific limits and guidelines.
