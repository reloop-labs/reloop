# Mail Service

The Reloop Mail Service provides powerful email sending capabilities with advanced features like templates, tracking, and delivery management.

## Overview

- **Base URL:** `/api/mail`
- **Version:** v1
- **Authentication:** Bearer tokens, API keys
- **Rate Limits:** 100 emails per minute per API key

## Quick Start

### 1. Send Your First Email

```bash
curl -X POST https://reloop.sh/api/mail/v1/send \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "to": "user@example.com",
    "subject": "Welcome to Reloop!",
    "html": "<h1>Welcome!</h1><p>Thank you for joining us.</p>",
    "text": "Welcome! Thank you for joining us."
  }'
```

### 2. Use Templates

```bash
curl -X POST https://reloop.sh/api/mail/v1/send-template \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "to": "user@example.com",
    "template": "welcome-email",
    "variables": {
      "name": "John Doe",
      "company": "Acme Corp"
    }
  }'
```

## API Endpoints

### Email Sending
- `POST /api/mail/v1/send` - Send individual email
- `POST /api/mail/v1/send-bulk` - Send bulk emails
- `POST /api/mail/v1/send-template` - Send template-based email

### Template Management
- `GET /api/mail/v1/templates` - List templates
- `POST /api/mail/v1/templates` - Create template
- `PUT /api/mail/v1/templates/{id}` - Update template
- `DELETE /api/mail/v1/templates/{id}` - Delete template

### Analytics
- `GET /api/mail/v1/analytics/opens` - Get open statistics
- `GET /api/mail/v1/analytics/clicks` - Get click statistics
- `GET /api/mail/v1/analytics/deliveries` - Get delivery statistics

### Webhooks
- `POST /api/mail/v1/webhooks` - Configure webhooks
- `GET /api/mail/v1/webhooks` - List webhooks
- `DELETE /api/mail/v1/webhooks/{id}` - Delete webhook

## Email Templates

### Template Variables

Templates support dynamic variables using the `{{variable}}` syntax:

```html
<h1>Welcome {{name}}!</h1>
<p>Thank you for joining {{company}}.</p>
<p>Your account is now active.</p>
```

### Template Categories

- **Transactional:** Account notifications, password resets
- **Marketing:** Newsletters, promotional emails
- **System:** System alerts, maintenance notices

## Error Codes

| Code | Description |
|------|-------------|
| 400 | Bad Request - Invalid email format or template |
| 401 | Unauthorized - Invalid API key |
| 403 | Forbidden - Insufficient permissions |
| 429 | Too Many Requests - Rate limit exceeded |
| 500 | Internal Server Error - Delivery failure |
