# Domain Service

> Manages domain configuration, DNS record generation (SPF, DKIM, DMARC), and domain verification for email sending. This service helps users configure their existing domains to send emails through Reloop.

<Callout type="info" title="Prerequisite">
Make sure you've completed the [local setup guide](/setup) first (clone repo, install Bun, and set up dependencies). You also need PostgreSQL and Redis running.
</Callout>

### Start the Service

```bash
bun run --filter=domain dev
```

**Expected output:**
```
Domain Server is running on http://localhost:8011/api/domain
Redis connected
Postgres connected
```
### Verify Service is Running

```bash
# Check health endpoint
curl http://localhost:8011/api/domain/

# Check Redis health
curl http://localhost:8011/api/domain/health/redis

# Check Postgres health
curl http://localhost:8011/api/domain/health/postgres
```

**Expected response:** Service status with ASCII art showing database connections.

## Database Schema

The domain service uses two main tables to store domain and DNS record information. The schema is defined in `packages/db/src/schema/domain.ts`.

### Enums

The schema defines four enums used across the domain tables:

| Enum | Values | Description |
|------|--------|-------------|
| **Domain Type** (`domain_type`) | `custom`, `subdomain`, `system` | Type of domain: `custom` = user's own domain, `subdomain` = subdomain of user's domain, `system` = system-managed domain |
| **Domain Status** (`domain_status`) | `start-verify`, `verifying`, `active`, `suspended`, `failed` | Verification and operational status of the domain |
| **DNS Record Type** (`dns_record_type`) | `A`, `AAAA`, `CNAME`, `MX`, `TXT` | Standard DNS record types (RFC-compliant) |
| **DNS Record Type Name** (`dns_record_type_name`) | `MX`, `SPF`, `DKIM`, `DMARC` | Semantic classification for email authentication records |

**DNS Record Type:**
- `A`: IPv4 address record
- `AAAA`: IPv6 address record
- `CNAME`: Canonical name record (alias)
- `MX`: Mail exchange record (email routing)
- `TXT`: Text record (used for SPF, DKIM, DMARC)

**DNS Record Type Name:**
- `MX`: Mail exchange record
- `SPF`: Sender Policy Framework record (stored as TXT)
- `DKIM`: DomainKeys Identified Mail record (stored as TXT)
- `DMARC`: Domain-based Message Authentication record (stored as TXT)

### Domain Table

The `domain` table stores domain information and verification status.

| Column | Type | Constraints | Default |
|--------|------|-------------|---------|
| `id` | `text` | Primary Key | `domain_{cuid}` |
| `domain` | `varchar(255)` | Not Null | - |
| `organizationId` | `text` | Not Null, FK → `organization.id` | - |
| `userId` | `text` | Not Null, FK → `user.id` | - |
| `domainType` | `domain_type` enum | Not Null | `custom` |
| `status` | `domain_status` enum | Not Null | `start-verify` |
| `userVerified` | `boolean` | Not Null | `false` |
| `systemVerified` | `boolean` | Not Null | `false` |
| `trackingDomain` | `boolean` | Not Null | `false` |
| `verificationFailedReason` | `text` | Nullable | - |
| `deletedAt` | `timestamp` | Nullable | - |
| `lastVerifiedAt` | `timestamp` | Nullable | - |
| `createdAt` | `timestamp` | Not Null | `now()` |
| `updatedAt` | `timestamp` | Not Null | `now()` |

**Key Constraints:**
- Unique constraint on `(organizationId, domain)` - prevents duplicate domains per organization
- Foreign keys cascade delete to `organization` and `user` tables

### Domain DNS Record Table

The `domain_dns_record` table stores individual DNS records associated with domains.

| Column | Type | Constraints | Default |
|--------|------|-------------|---------|
| `id` | `text` | Primary Key | `dns_{cuid}` |
| `domainId` | `text` | Not Null, FK → `domain.id` | - |
| `organizationId` | `text` | Not Null, FK → `organization.id` | - |
| `userId` | `text` | Not Null, FK → `user.id` | - |
| `recordType` | `dns_record_type` enum | Not Null | - |
| `recordTypeName` | `dns_record_type_name` enum | Not Null | - |
| `name` | `text` | Not Null | - |
| `status` | `domain_status` enum | Not Null | `start-verify` |
| `value` | `text` | Not Null | - |
| `ttl` | `string` | Not Null | `Auto` |
| `priority` | `integer` | Nullable | - |
| `domain` | `text` | Not Null | - |
| `privateKey` | `text` | Nullable | - |
| `verificationError` | `text` | Nullable | - |
| `deletedAt` | `timestamp` | Nullable | - |
| `createdAt` | `timestamp` | Not Null | `now()` |
| `updatedAt` | `timestamp` | Not Null | `now()` |

**Key Constraints:**
- Unique constraint on `(domainId, recordType, name, value)` - prevents duplicate records
- Foreign keys cascade delete to `domain`, `organization`, and `user` tables

### Relationships

- **Domain → Organization**: Many-to-one (domain belongs to one organization)
- **Domain → User**: Many-to-one (domain created by one user)
- **Domain → DNS Records**: One-to-many (domain has many DNS records)
- **DNS Record → Domain**: Many-to-one (DNS record belongs to one domain)
- **DNS Record → Organization**: Many-to-one (DNS record belongs to one organization)
- **DNS Record → User**: Many-to-one (DNS record created by one user)

### DNS Related Details

**MX Record:**
- Type: `MX`
- Name: `send.example.com`
- Value: `mail.reloop.sh`
- Priority: `10`
- **Purpose:** Tells email servers where to deliver incoming emails

**SPF Record:**
- Type: `TXT`
- Name: `send.example.com`
- Value: `v=spf1 include:mail.reloop.sh ~all`
- **Purpose:** Authorizes mail.reloop.sh to send emails on behalf of the domain

**DKIM Record:**
- Type: `TXT`
- Name: `reloop._domainkey.send.example.com`
- Value: `v=DKIM1; k=rsa; p=[public key]`
- **Purpose:** Provides public key for email signature verification
- **How it's generated:** Creates 2048-bit RSA key pair, stores private key, publishes public key

**DMARC Record:**
- Type: `TXT`
- Name: `_dmarc.send.example.com`
- Value: `v=DMARC1; p=none;`
- **Purpose:** Sets email authentication policy (monitor mode)
