# Project Structure

A modern monorepo with clear separation between apps, shared packages, and development tools.

<Callout type="info" title="Tech Stack">
  See **[Tech Stack](/setup/tech-stack)** for technology details.
</Callout>

## Quick Overview

```
reloop/
├── apps/
│   ├── backend/
│   │   ├── auth/      # Authentication service
│   │   ├── mail/      # Email service
│   │   ├── server/    # Main API server
│   │   └── webhook/   # Webhook handler
│   └── frontend/
│       ├── admin/     # Admin dashboard
│       ├── dev/       # Development docs
│       ├── docs/      # Production docs
│       ├── dashboard/      # Core app
│       └── web/       # Marketing site
├── packages/          # Shared libraries
└── tools/            # Dev configs & utilities
```

## Key Benefits

- **Shared code**: Reusable packages across apps
- **Consistent tooling**: Unified configs and build setup
- **Clear boundaries**: Each app has a specific purpose
- **Easy scaling**: Add new apps without affecting others
