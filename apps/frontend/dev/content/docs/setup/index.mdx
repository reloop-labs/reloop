# Setup

Get Reloop running on your local machine for development.

import { Callout } from 'fumadocs-ui/components/callout'

<Callout>
  **Prerequisite:** Make sure <strong>Bun</strong> is installed before starting.
</Callout>

## Option 1: One-Command Setup

Run this single command to clone, navigate, and install everything:

```sh
git clone git@github.com:reloop-labs/reloop.git && cd reloop && bun install
```

---

## Option 2: Manual Setup

Follow these steps if you prefer to run commands individually:

### Install Bun

If you don't have Bun installed, run:

```sh
curl -fsSL https://bun.sh/install | bash
```

**More details:** [https://bun.com/get](https://bun.com/get)

### 1. Clone the Repository

```sh
git clone git@github.com:reloop-labs/reloop.git
```

### 2. Navigate to Project Directory

```sh
cd reloop
```

### 3. Install Dependencies

```sh
bun install
```

### 4. Configure Hosts File

**Important:** This step is crucial for running multiple servers on the same network. Since Reloop consists of several services (backend, frontend, mail, etc.) that need to communicate with each other, you must add a local domain entry to your hosts file.

This allows all services to run on different ports but appear to be on the same domain, enabling proper communication between components.

```sh
echo "127.0.0.1 reloop.local" | sudo tee -a /etc/hosts
```

**What this does:**
- Maps `reloop.local` to your local machine (`127.0.0.1`)
- Enables services to communicate using the same domain name
- Prevents network conflicts when running multiple servers
- Allows proper routing between frontend, backend, and other services

**Note:** You may need to enter your system password when running this command with `sudo`.
