## Backend & API

Robust server-side technologies for handling business logic and data processing.

<Cards>
  <Card icon={<ElysiaJSIcon />} title="ElysiaJS" href="https://elysiajs.com/">
    **Backend Framework** - Fast, modern, type-safe framework for building APIs and services.
    - **Used in**: Server
  </Card>

  <Card icon={<Icon name="mail" />} title="Postfix" href="http://www.postfix.org/">
    **Mail Transfer Agent** - Trusted MTA for sending transactional and system emails.
    - **Used in**: Email infrastructure
  </Card>

  <Card icon={<Icon name="inbox" />} title="Dovecot" href="https://www.dovecot.org/">
    **Email Server** - Works alongside Postfix to manage email delivery and storage.
    - **Used in**: Email infrastructure
  </Card>

  <Card icon={<Icon name="shield-check" />} title="Rspamd" href="https://rspamd.com/">
    **Spam Filtering** - Advanced spam filtering system for email deliverability analysis.
    - **Used in**: Email infrastructure
  </Card>
</Cards>
