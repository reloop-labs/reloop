# Frontend Web Service

> Powers Reloop's landing pages and marketing sites.

<Callout type="info" title="Prerequisite">
Make sure you've completed the [local setup guide](/setup) first (clone repo, install Bun, and set up dependencies).
</Callout>

---

## Quick Start

```bash
# One command to get started
cd apps/frontend/web && cp .env.example .env && bun i && bun dev
````

Open [http://localhost:3002](http://localhost:3002) 🎉

---

## Service Info

* **Location:** `/apps/frontend/web`
* **Port:** `3002` (configurable in `package.json`)
* **Tech Stack Guide:** [Frontend Technologies](/setup/tech-stack#frontend-technologies)
* **Part of Monorepo:** Yes (run with filters or inside service dir)

---

## Environment Setup

Create `.env` file:

```bash
# Development
NEXT_PUBLIC_WEB_URL="http://localhost:3002"

# Production
NEXT_PUBLIC_WEB_URL="https://reloop.sh"
```

| Variable              | Required | Description                                          |
| --------------------- | -------- | ---------------------------------------------------- |
| `NEXT_PUBLIC_WEB_URL` | ✅        | Base URL for frontend, used in redirects & API calls |

## Development Commands

```bash
# Install dependencies
bun i

# Start dev server
bun dev
# or from monorepo root with filter
bun run --filter=web dev

# Build for production
bun run --filter=web build

# Start production server
bun run --filter=web start

# Run tests
bun run test

# Lint & format code
bun run lint && bun run format
```

## Troubleshooting

**Port already in use?**
Update the port in `package.json`:

```json
{
  "scripts": {
    "dev": "next dev -p 3003"
  }
}
```

**Environment issues?**
Make sure your `.env` file exists and has the correct `NEXT_PUBLIC_WEB_URL` value.

**Bun install fails?**
Try clearing cache:

```bash
rm -rf ~/.bun/install/cache && bun i
```
