# Frontend Web Service

> Powers Reloop's landing pages, marketing sites, and public-facing web interfaces. This Next.js application serves as the primary entry point for users discovering and engaging with the Reloop platform.

<Callout type="info" title="Prerequisite">
Make sure you've completed the [local setup guide](/setup) first (clone repo, install Bun, and set up dependencies).
</Callout>

## Quick Start

```bash
# One command to get started
cd apps/frontend/web && cp .env.example .env && bun i && bun dev
```

Open [http://localhost:3002](http://localhost:3002) 🎉

### Verify Everything Works

After starting the dev server, you should see:
- ✅ Landing page loads without errors
- ✅ Hot reload works when editing files
- ✅ Console shows no critical errors
- ✅ API endpoints respond (check Network tab)

## Environment Setup

Create `.env` file:

```bash
# Development
NEXT_PUBLIC_WEB_URL="http://localhost:3002"
NEXT_PUBLIC_API_URL="http://localhost:3001"

# Production
NEXT_PUBLIC_WEB_URL="https://reloop.sh"
NEXT_PUBLIC_API_URL="https://api.reloop.sh"

# Optional: Analytics & Monitoring
NEXT_PUBLIC_ANALYTICS_ID=""
```

| Variable                   | Required | Description                                          |
| -------------------------- | -------- | ---------------------------------------------------- |
| `NEXT_PUBLIC_WEB_URL`      | ✅        | Base URL for frontend, used in redirects & API calls |
| `NEXT_PUBLIC_API_URL`      | ✅        | Backend API endpoint for data fetching               |
| `NEXT_PUBLIC_ANALYTICS_ID` | ❌        | Analytics tracking ID (Google Analytics, etc.)      |

## Development Commands

```bash
# Install dependencies
bun i

# Start dev server
bun dev
# or from monorepo root with filter
bun run --filter=web dev

# Build for production
bun run build
# or from monorepo root
bun run --filter=web build

# Start production server locally
bun run start
# or from monorepo root
bun run --filter=web start

# Run tests
bun run test
bun run test:watch  # Watch mode

# Lint & format code
bun run lint && bun run format

# Type checking
bun run type-check
```

## Troubleshooting

### Port Issues
**Port already in use?**
```bash
# Check what's using the port
lsof -i :3002

# Kill the process (replace PID)
kill -9 <PID>

# Or update port in package.json
```

```json
{
  "scripts": {
    "dev": "next dev -p 3003"
  }
}
```

### Build/Install Issues
**Bun install fails?**
```bash
# Clear cache and reinstall
rm -rf ~/.bun/install/cache
rm -rf node_modules
bun i

# Check Bun version
bun --version
```
