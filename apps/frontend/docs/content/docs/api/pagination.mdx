---
title: Pagination
description: Handle paginated list responses from the Reloop API.
---

List endpoints use offset-based pagination. Use the `page` and `limit` query parameters to paginate results.

## Query Parameters

| Parameter | Type | Default | Max | Description |
|-----------|------|---------|-----|-------------|
| `page` | `number` | `1` | — | The page number to retrieve. |
| `limit` | `number` | `20` | `100` | The number of records to return per page. |

## Response Structure

Pagination metadata is returned directly at the root of the JSON response:

- `total` — The total number of items matching the query.
- `page` — The current page number.
- `limit` — The page limit.

### Example Responses

```json
// GET /api/contacts/list
{
  "object": "contact",
  "contacts": [...],
  "total": 120,
  "page": 1,
  "limit": 20,
  "totalContacts": 120,
  "subscribedContacts": 100,
  "unsubscribedContacts": 20,
  "event": "contact.list"
}
```

```json
// GET /api/template/list
{
  "templates": [...],
  "total": 45,
  "page": 1,
  "limit": 20,
  "event": "template.list"
}
```
