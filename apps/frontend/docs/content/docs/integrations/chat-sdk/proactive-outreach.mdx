Start new email conversations proactively with the Chat SDK adapter. Instead of only responding to incoming emails, your agent can initiate conversations with users.

## Prerequisites

- [Chat SDK setup](/integrations/chat-sdk) completed
- A verified sending domain

## Starting a new conversation

Use `chat.startThread` to create a new email thread and send the first message:

<CodeBlock title="Proactive Outreach">
```typescript
// Start a new conversation
const thread = await chat.startThread({
  adapter: 'reloop',
  participants: ['user@example.com'],
});

await thread.post('Hi! I noticed your trial is ending in 3 days. Would you like to upgrade to a paid plan?');
```
</CodeBlock>

## Use cases

### Welcome emails

```typescript
async function sendWelcomeEmail(userEmail: string, userName: string) {
  const thread = await chat.startThread({
    adapter: 'reloop',
    participants: [userEmail],
  });

  await thread.post(
    `Welcome to Acme, ${userName}! 🎉\n\n` +
    `I'm your AI assistant. I can help you:\n` +
    `• Set up your account\n` +
    `• Answer questions about our product\n` +
    `• Schedule a demo\n\n` +
    `Just reply to this email anytime!`
  );
}
```

### Scheduled check-ins

```typescript
import cron from 'node-cron';

// Weekly check-in every Monday at 9am
cron.schedule('0 9 * * 1', async () => {
  const activeUsers = await getActiveUsers();

  for (const user of activeUsers) {
    const thread = await chat.startThread({
      adapter: 'reloop',
      participants: [user.email],
    });

    const summary = await generateWeeklySummary(user.id);
    await thread.post(
      `Good morning, ${user.name}! Here's your weekly summary:\n\n${summary}`
    );
  }
});
```

### Alert notifications

```typescript
async function sendAlert(userEmail: string, alert: Alert) {
  const thread = await chat.startThread({
    adapter: 'reloop',
    participants: [userEmail],
  });

  await thread.post(
    `⚠️ Alert: ${alert.title}\n\n` +
    `${alert.description}\n\n` +
    `Severity: ${alert.severity}\n` +
    `Time: ${alert.timestamp}\n\n` +
    `Reply to this email to acknowledge.`
  );

  // Subscribe to get the user's reply
  await thread.subscribe();
}

// Handle acknowledgments
chat.onSubscribedMessage(async (thread, message) => {
  await acknowledgeAlert(thread.id);
  await thread.post('Alert acknowledged. Thank you!');
});
```

## Best practices

<Tip>
- **Respect sending limits**: Don't spam users with too many proactive emails. Implement rate limiting.
- **Allow opt-out**: Always provide a way for users to stop receiving proactive emails.
- **Use appropriate timing**: Send emails during business hours when possible.
- **Subscribe to threads**: Call `thread.subscribe()` after starting a thread if you want to handle replies.
- **Track threads**: Store thread IDs to avoid creating duplicate conversations.
</Tip>

<Warning>
Proactive outreach emails are subject to the same deliverability best practices as any other email. Sending too many unsolicited emails can harm your domain reputation. See [Email Best Practices](/integrations/email-best-practices) for guidance.
</Warning>
