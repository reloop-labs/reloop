Build HTML emails using React components with AI agents. This skill teaches your AI agent how to create beautiful, responsive emails using the [React Email](https://react.email) component library.

## Installation

The React Email skill is part of the [reloop-skills](https://github.com/reloop-labs/reloop-skills) collection:

```bash
npx skills add reloop/react-email
```

## Advantages

- **Component-based design**: Build emails from reusable React components like `<Button>`, `<Section>`, `<Column>`, and more.
- **Cross-client compatibility**: React Email components render correctly across all major email clients (Gmail, Outlook, Apple Mail, etc.).
- **TypeScript support**: Full type safety for email templates.
- **Preview in browser**: Preview emails in your browser during development.
- **Inline styles**: Automatically inlines CSS for maximum email client compatibility.

## What's included

The skill provides your agent with knowledge about:

- All available React Email components and their props
- Email layout best practices (tables, responsive design)
- How to render React Email templates to HTML
- Integration with Reloop's send API
- Common patterns for transactional emails, marketing emails, and notifications
