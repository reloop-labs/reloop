Integrate Reloop with [Lovable](https://lovable.dev) to add email capabilities to your AI-generated applications.

## Overview

Lovable is an AI-powered app builder that lets you create full-stack applications from natural language descriptions. By integrating Reloop, your Lovable-built apps can send transactional emails, notifications, and more.

## Setup

<Steps>
  <Step title="Get your Reloop API key">
    Create an API key at [app.reloop.dev/api-keys](https://app.reloop.dev/api-keys).
  </Step>
  <Step title="Add the Reloop SDK">
    In your Lovable project, tell the AI to install the Reloop SDK:
    ```
    Install the reloop package and set up email sending functionality.
    ```
  </Step>
  <Step title="Configure environment variables">
    Add your `RELOOP_API_KEY` to your Lovable project's environment variables.
  </Step>
  <Step title="Send your first email">
    Ask Lovable's AI to create an email sending function:
    ```
    Create a server action that sends a welcome email to new users using the Reloop SDK.
    ```
  </Step>
</Steps>

## Example prompt

Use this prompt to get started quickly in Lovable:

```
I want to add email functionality to my app using Reloop (reloop npm package).
Set up:
1. A server action to send emails using the Reloop API
2. A welcome email that's sent when a user signs up
3. Use my verified domain: notifications@mydomain.com

My Reloop API key is stored in the RELOOP_API_KEY environment variable.
```
