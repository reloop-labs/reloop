Point Coolify at Reloop SMTP. The same API key sends Coolify's password resets and alerts, and mail from the apps you deploy there.

Create the key in the [Reloop dashboard](https://reloop.sh/dashboard/api-keys). The address you send from has to be on a [verified domain](https://reloop.sh/dashboard/domain).

## Coolify's own email

<Steps>
  <Step title="Open email settings">
    In Coolify, go to **Settings → Email**.

    ![Coolify email settings](/docs/images/docs/integrations/coolify-email.png)
  </Step>
  <Step title="Enter the Reloop server">
    Turn SMTP on and use these values. The username and the password are both your API key.

    | Field | Value |
    | :--- | :--- |
    | **Host** | `smtp.reloop.sh` |
    | **Port** | `587` |
    | **Encryption** | `StartTLS` |
    | **SMTP username** | Your API key (`rl_...`) |
    | **SMTP password** | The same API key |
    | **From address** | `hello@yourdomain.com` |
    | **From name** | `Coolify` |
  </Step>
  <Step title="Save and send a test">
    Click **Save**, then send the test from the same page. The message shows up in your [Reloop logs](https://reloop.sh/dashboard).
  </Step>
</Steps>

## Apps you deploy on Coolify

<Steps>
  <Step title="Add the API key">
    Open the application, go to **Environment Variables**, and add the key as a secret.

    ```bash
    RELOOP_API_KEY=rl_your_api_key
    ```
  </Step>
  <Step title="Redeploy">
    Save and redeploy so the app picks up the key. Send with the [SMTP relay](/docs/examples/smtp/introduction) or an [SDK](/docs).
  </Step>
</Steps>

To run Reloop itself on Coolify, follow [Deploy on Coolify](/docs/self-host/coolify).
