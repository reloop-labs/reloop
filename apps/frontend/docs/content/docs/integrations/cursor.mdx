[Cursor](https://cursor.com) is an AI-first code editor. Connect it to the Reloop MCP server and the Cursor agent can send test emails, look up contacts, check domains, and manage templates directly from the chat window.

## Connect Cursor

Add the hosted server and sign in with your Reloop account. No API key needed.

```json
{
  "mcpServers": {
    "reloop": {
      "url": "https://reloop.sh/mcp"
    }
  }
}
```

Put this in `.cursor/mcp.json`, then click **Connect** next to reloop in **Cursor Settings → MCP & Integrations**.

## Use it in chat

In the Cursor chat panel, try:

> "Send a test email to customer@example.com saying 'Hello from Cursor!' using Reloop."

See [example prompts](/docs/integrations/ai-tools/mcp-prompts) for more, and the [MCP server overview](/docs/integrations/ai-tools/mcp-server) for everything the server can do.
