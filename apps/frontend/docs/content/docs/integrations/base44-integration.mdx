Integrate Reloop with [Base44](https://base44.com) to add email functionality to your AI-built applications.

## Overview

Base44 is an AI-powered platform for building web applications. With Reloop, you can add transactional email capabilities to your Base44 projects.

## Setup

<Steps>
  <Step title="Get your Reloop API key">
    Create an API key at [app.reloop.dev/api-keys](https://app.reloop.dev/api-keys).
  </Step>
  <Step title="Add Reloop to your project">
    In your Base44 project, add the Reloop SDK:
    ```bash
    npm install reloop
    ```
  </Step>
  <Step title="Configure environment variables">
    Add your `RELOOP_API_KEY` to your project's environment configuration.
  </Step>
  <Step title="Send emails">
    Create an email sending function:
    ```javascript
    import { Reloop } from 'reloop';
    const reloop = new Reloop(process.env.RELOOP_API_KEY);
    export async function sendEmail({ to, subject, html }) {
      const { data, error } = await reloop.emails.send({
        from: 'notifications@yourdomain.com',
        to,
        subject,
        html,
      });
      if (error) {
        console.error('Email send failed:', error);
        throw error;
      }
      return data;
    }
    ```
  </Step>
</Steps>
