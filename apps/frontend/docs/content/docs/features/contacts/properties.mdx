**Properties** are custom fields attached to contact records in Reloop. By defining custom properties, you can store structured data points (such as subscription tiers, sign-up sources, account age, or user preferences) and use them to personalize emails and filter contacts.

![Contact Properties View](/docs/images/docs/contacts/properties-list.png)

---

## Key Concepts

* **Supported Types**: Custom properties can be created as either a **String** (free-form text, e.g., `"enterprise"`) or a **Number** (integer/decimal, e.g., `42`).
* **Default Values**: Optional fallbacks used during email template compilation when a specific contact does not have a value populated for that property.

---

## Dashboard Usage

You can define and manage custom properties directly inside the Reloop Dashboard.

### 1. Creating a Custom Property
1. Navigate to **Contacts** in the sidebar and click on the **Properties** tab.
2. Click the **Add Property** button.
3. Configure the fields:
   * **Name**: The identifier for the custom property. Naming must follow these validation rules:
     * Only letters, numbers, and underscores are allowed.
     * The name must start with a letter or underscore.
     * Spaces will be automatically converted to underscores.
   * **Type**: Select **String** or **Number**.
   * **Default Value** (Optional): Provide a fallback value. If the type is **Number**, the fallback must be a valid numeric value.
4. Click **Add Property** to save.

### 2. Deleting a Custom Property
1. In the **Properties** list view, locate the property you wish to remove.
2. Select the dropdown menu options on the property row, and click **Delete**.
3. Confirming deletion will remove the property schema. Existing contacts will retain their raw key-value values, but the field will no longer be managed globally.

## Technical Reference

### Property Schema

| Field Name | Type | Description |
| :--- | :--- | :--- |
| `id` | `string` | Unique identifier generated by Reloop. |
| `propertyName` | `string` | The slugified identifier name of the custom property. |
| `propertyType` | `string` | The type representation: `string` or `number`. |
| `defaultValue` | `string \| null` | The default fallback value for contacts missing this field. |

### API Endpoint

#### Create a Custom Property

```http
POST /api/contacts/v1/properties/create
Content-Type: application/json
```

**Request Payload:**

```json
{
  "name": "company_plan",
  "type": "string",
  "fallbackValue": "free"
}
```

**Response (200 OK):**

```json
{
  "id": "prop_928174921",
  "propertyName": "company_plan",
  "propertyType": "string",
  "defaultValue": "free",
  "createdAt": "2026-06-15T12:00:00.000Z"
}
```
