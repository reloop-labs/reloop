Reloop **Contacts** enables you to build, manage, and organize your subscriber and customer list. By storing contact information, tracking their subscription status, and appending custom properties, you can design highly personalized and targeted communication workflows.

![Contacts List View](/docs/images/docs/contacts/list-view.png)

---

## Dashboard Usage

The Reloop Dashboard provides a visual and intuitive interface to manage your contact database.

### 1. Navigating Contacts
In the left sidebar of the dashboard, expand the **Contacts** accordion. Click on the main navigation link to view your Contact table. Here, you can search for contacts by name or email, filter them by status, and view their metadata.

### 2. Adding Contacts Manually
To add a single contact:
1. Click the **Add Contact** button at the top-right of the Contacts list view.
2. In the modal, fill in the required fields:
   * **Email**: The unique email address for the contact.
   * **First Name** & **Last Name** (Optional): Details to personalize your outbound communications.
   * **Status**: Set their subscription state to **Subscribed** or **Unsubscribed**.
3. Optionally choose any **Groups** or **Channels** to enroll the contact in directly.
4. Click **Add Contact** to save.

### 3. Bulk Importing via CSV
To import multiple contacts at once:
1. Navigate to **Contacts** and click the **Bulk Import** button.
2. Upload a standard CSV file. The columns should match your contact schema (e.g., `email`, `firstName`, `lastName`).
3. Map the fields in your CSV to the existing properties in Reloop.
4. Run the import to populate your database instantly.

## Technical Reference

### Contact Schema

Each contact record in Reloop is represented by the following structure:

| Field Name | Type | Description |
| :--- | :--- | :--- |
| `id` | `string` | Unique identifier generated by Reloop. |
| `email` | `string` | The unique contact email address. |
| `status` | `string` | Subscription status: `subscribed` or `unsubscribed`. |
| `firstName` | `string \| null` | Optional first name of the contact. |
| `lastName` | `string \| null` | Optional last name of the contact. |
| `properties` | `object` | Key-value pairs containing custom metadata/traits. |
| `createdAt` | `string` | ISO 8601 timestamp indicating when the contact was created. |
| `updatedAt` | `string` | ISO 8601 timestamp indicating when the contact was last updated. |

### JSON Representation

```json
{
  "id": "con_8371904721",
  "email": "alex.doe@example.com",
  "status": "subscribed",
  "firstName": "Alex",
  "lastName": "Doe",
  "properties": {
    "company_plan": "enterprise",
    "signup_date": "2026-06-15"
  },
  "createdAt": "2026-06-15T12:00:00.000Z",
  "updatedAt": "2026-06-15T12:05:00.000Z"
}
```
