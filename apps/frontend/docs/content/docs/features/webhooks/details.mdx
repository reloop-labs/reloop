### Key Capabilities

* **Multiple Subscriptions**: Set up different endpoints for specific sets of events.
* **Event Selection**: Choose precisely which events to listen to (e.g. `email.delivered`, `email.bounced`, `link.clicked`).
* **Cryptographic Signatures**: Verify webhook payloads securely using shared secrets and signature headers.
* **Retry and Replay Logs**: Inspect webhook delivery failures and replay event logs directly.
