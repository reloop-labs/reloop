## Configuration

Update your `.env` file with the following settings:

```bash
MAIL_MAILER=smtp
MAIL_HOST=smtp.reloop.sh
MAIL_PORT=587
MAIL_USERNAME=reloop
MAIL_PASSWORD=re_123456789
MAIL_ENCRYPTION=tls
MAIL_FROM_ADDRESS=onboarding@reloop.dev
MAIL_FROM_NAME="${APP_NAME}"
```

Replace `re_123456789` with your actual Reloop API key.

## Usage

You can now use Laravel's standard `Mail` facade:

```php
use Illuminate\Support\Facades\Mail;

Mail::raw('It works!', function ($message) {
    $message->to('delivered@reloop.dev')
            ->subject('Hello from Laravel SMTP');
});
```
