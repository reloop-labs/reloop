## Configuration

1. Log in to your **Auth0 Dashboard**.
2. Navigate to **Branding > Email Provider**.
3. Enable the **Custom Email Provider** toggle.
4. Select **SMTP** from the provider list.
5. Enter the following settings:

| Field | Value |
| :--- | :--- |
| **From** | `onboarding@yourdomain.com` |
| **Host** | `smtp.reloop.sh` |
| **Port** | `587` |
| **Username** | `reloop` |
| **Password** | Your Reloop API Key (`re_123...`) |

6. Click **Save**.

## Verification

You can use the **Send Test Email** button in the Auth0 dashboard to verify that the connection is working correctly.
