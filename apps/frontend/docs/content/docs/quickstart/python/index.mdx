## Prerequisites

To get the most out of this guide, you'll need to:

* [Create an API key](/learn/api-keys)
* [Verify your domain](/learn/domain)
* Have Python 3.7 or later installed

## 1. Install

Install the Reloop Python SDK using pip:

<CodeGroup>
```bash pip
pip install reloop-email
```
</CodeGroup>

## 2. Usage

Create a `main.py` file and add the following code:

<CodeGroup>
```python main.py
import reloop

client = reloop.Client(api_key="re_123456789")

params = {
    "from": "Acme <onboarding@reloop.dev>",
    "to": ["delivered@reloop.dev"],
    "subject": "Hello from Python",
    "html": "<strong>It works!</strong>",
}

try:
    email = client.emails.send(params)
    print(f"Email sent successfully: {email['id']}")
except Exception as e:
    print(f"Error sending email: {e}")
```
</CodeGroup>
