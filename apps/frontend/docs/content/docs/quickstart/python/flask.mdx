## Prerequisites

To get the most out of this guide, you'll need to:

* [Create an API key](/learn/api-keys)
* [Verify your domain](/learn/domain)
* Have an existing Flask project

## 1. Install

Install the Reloop Python SDK:

<CodeGroup>
```bash pip
pip install reloop-email
```
</CodeGroup>

## 2. Usage

Set up a simple Flask route to send an email:

<CodeGroup>
```python app.py
from flask import Flask, jsonify
import reloop
import os

app = Flask(__name__)
client = reloop.Client(api_key=os.environ.get("RELOOP_API_KEY"))

@app.route("/send-email", methods=["POST"])
def send_email():
    try:
        response = client.emails.send({
            "from": "Acme <onboarding@reloop.dev>",
            "to": ["delivered@reloop.dev"],
            "subject": "Hello from Flask",
            "html": "<strong>It works with Flask!</strong>",
        })
        return jsonify(response), 200
    except Exception as e:
        return jsonify({"error": str(e)}), 500

if __name__ == "__main__":
    app.run(debug=True)
```
</CodeGroup>
