## Prerequisites

To get the most out of this guide, you'll need to:

* [Create an API key](/learn/api-keys)
* [Verify your domain](/learn/domain)
* Have an existing Phoenix project

## 1. Install

Add `reloop` to your `mix.exs`:

<CodeGroup>
```elixir mix.exs
def deps do
  [
    {:reloop, "~> 0.1.0"},
    {:swoosh, "~> 1.0"}
  ]
end
```
</CodeGroup>

## 2. Configuration

Configure Swoosh to use the Reloop adapter in `config/config.exs`:

<CodeGroup>
```elixir config/config.exs
config :my_app, MyApp.Mailer,
  adapter: Swoosh.Adapters.Reloop,
  api_key: System.get_env("RELOOP_API_KEY")
```
</CodeGroup>

## 3. Usage

Now you can use standard Swoosh mailers:

<CodeGroup>
```elixir lib/my_app/mailer.ex
defmodule MyApp.WelcomeEmail do
  import Swoosh.Email

  def welcome(user) do
    new()
    |> from({"Acme", "onboarding@reloop.dev"})
    |> to(user.email)
    |> subject("Welcome to Phoenix + Reloop")
    |> html_body("<strong>It works!</strong>")
  end
end
```
</CodeGroup>
