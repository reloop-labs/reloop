## Prerequisites

To get the most out of this guide, you'll need to:

* [Create an API key](/learn/api-keys)
* [Verify your domain](/learn/domain)
* Have Elixir installed

## 1. Install

Add `reloop` to your list of dependencies in `mix.exs`:

<CodeGroup>
```elixir mix.exs
def deps do
  [
    {:reloop, "~> 0.1.0"}
  ]
end
```
</CodeGroup>

And then run:

<CodeGroup>
```bash
mix deps.get
```
</CodeGroup>

## 2. Usage

You can send an email using the `Reloop.Emails.send/1` function:

<CodeGroup>
```elixir main.ex
reloop = Reloop.new("re_123456789")

Reloop.Emails.send(reloop, %{
  from: "Acme <onboarding@reloop.dev>",
  to: ["delivered@reloop.dev"],
  subject: "Hello from Elixir",
  html: "<strong>It works!</strong>"
})
```
</CodeGroup>
