## Prerequisites

To get the most out of this guide, you'll need to:

* [Create an API key](/learn/api-keys)
* [Verify your domain](/learn/domain)
* Have Go 1.18 or later installed

## 1. Install

Install the Reloop Go SDK:

<CodeGroup>
```bash go
go get github.com/reloop-labs/reloop-email
```
</CodeGroup>

## 2. Usage

Create a `main.go` file and add the following code:

<CodeGroup>
```go main.go
package main

import (
	"context"
	"fmt"
	"log"

	"github.com/reloop-labs/reloop-email"
)

func main() {
	client := reloop.NewClient("re_123456789")

	params := &reloop.SendEmailParams{
		From:    "Acme <onboarding@reloop.dev>",
		To:      []string{"delivered@reloop.dev"},
		Subject: "Hello from Go",
		Html:    "<strong>It works!</strong>",
	}

	res, err := client.Emails.Send(context.Background(), params)
	if err != nil {
		log.Fatal(err)
	}

	fmt.Printf("Email sent successfully: %s\n", res.ID)
}
```
</CodeGroup>
