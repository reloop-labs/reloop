## Prerequisites

To get the most out of this guide, you'll need to:

* [Create an API key](/learn/api-keys)
* [Verify your domain](/learn/domain)
* Have an existing Sinatra project

## 1. Install

Install the Reloop gem:

<CodeGroup>
```bash
gem install reloop-email
```
</CodeGroup>

## 2. Usage

Set up a simple Sinatra route to send an email:

<CodeGroup>
```ruby app.rb
require 'sinatra'
require 'reloop'

reloop = Reloop::Client.new(api_key: ENV['RELOOP_API_KEY'])

post '/send-email' do
  reloop.emails.send(
    from: 'Acme <onboarding@reloop.dev>',
    to: ['delivered@reloop.dev'],
    subject: 'Hello from Sinatra',
    html: '<strong>It works with Sinatra!</strong>'
  )
  'Email sent!'
end
```
</CodeGroup>
