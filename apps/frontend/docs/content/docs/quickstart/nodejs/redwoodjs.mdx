## Prerequisites

To get the most out of this guide, you'll need to:

* [Create an API key](/learn/api-keys)
* [Verify your domain](/learn/domain)
* Have an existing RedwoodJS project

## 1. Install

Install the Reloop Node.js SDK in your `api` side:

<CodeGroup>
  ```bash npm
  npm install @reloop/node
  ```
  ```bash yarn
  yarn add @reloop/node
  ```
  ```bash pnpm
  pnpm add @reloop/node
  ```
  ```bash bun
  bun add @reloop/node
  ```
</CodeGroup>

## 2. Usage

You can use Reloop in a service or a function. Here's an example in a service:

<CodeGroup>
```typescript api/src/services/emails/emails.ts
import { Reloop } from '@reloop/node'

const reloop = new Reloop(process.env.RELOOP_API_KEY)

export const sendWelcomeEmail = async ({ email }) => {
  const { data, error } = await reloop.emails.send({
    from: 'Acme <onboarding@reloop.dev>',
    to: [email],
    subject: 'Welcome to RedwoodJS',
    html: '<strong>It works!</strong>',
  })

  if (error) {
    throw new Error(error.message)
  }

  return data
}
```
</CodeGroup>
