## Prerequisites

To get the most out of this guide, you'll need to:

* [Create an API key](/learn/api-keys)
* [Verify your domain](/learn/domain)
* Have JDK 11 or later installed

## 1. Install

Add the Reloop dependency to your `pom.xml`:

<CodeGroup>
```xml pom.xml
<dependency>
  <groupId>sh.reloop</groupId>
  <artifactId>reloop-java</artifactId>
  <version>0.1.0</version>
</dependency>
```
</CodeGroup>

## 2. Usage

Create a `Main.java` file and add the following code:

<CodeGroup>
```java Main.java
import sh.reloop.Reloop;
import sh.reloop.models.Email;
import sh.reloop.models.SendEmailResponse;

public class Main {
    public static void main(String[] args) {
        Reloop reloop = new Reloop("re_123456789");

        Email email = Email.builder()
            .from("Acme <onboarding@reloop.dev>")
            .to("delivered@reloop.dev")
            .subject("Hello from Java")
            .html("<strong>It works!</strong>")
            .build();

        try {
            SendEmailResponse response = reloop.emails().send(email);
            System.out.println("Email sent successfully: " + response.getId());
        } catch (Exception e) {
            System.err.println("Error sending email: " + e.getMessage());
        }
    }
}
```
</CodeGroup>
