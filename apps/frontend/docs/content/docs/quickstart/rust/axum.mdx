## Prerequisites

To get the most out of this guide, you'll need to:

* [Create an API key](/learn/api-keys)
* [Verify your domain](/learn/domain)
* Have an existing Axum project

## 1. Install

Add `reloop` to your `Cargo.toml`:

<CodeGroup>
```toml Cargo.toml
[dependencies]
reloop = "0.1.0"
axum = "0.7"
tokio = { version = "1", features = ["full"] }
```
</CodeGroup>

## 2. Usage

Set up an Axum route to send an email:

<CodeGroup>
```rust main.rs
use axum::{routing::post, Json, Router};
use reloop::{Client, SendEmailParams};
use std::sync::Arc;

struct AppState {
    reloop: Client,
}

#[tokio::main]
async fn main() {
    let reloop = Client::new("re_123456789");
    let state = Arc::new(AppState { reloop });

    let app = Router::new()
        .route("/send", post(send_email))
        .with_state(state);

    let listener = tokio::net::TcpListener::bind("0.0.0.0:3000").await.unwrap();
    axum::serve(listener, app).await.unwrap();
}

async fn send_email(
    axum::extract::State(state): axum::extract::State<Arc<AppState>>,
) -> Result<Json<serde_json::Value>, String> {
    let params = SendEmailParams {
        from: "Acme <onboarding@reloop.dev>".to_string(),
        to: vec!["delivered@reloop.dev".to_string()],
        subject: "Hello from Axum".to_string(),
        html: "<strong>It works!</strong>".to_string(),
        ..Default::default()
    };

    match state.reloop.emails.send(params).await {
        Ok(res) => Ok(Json(serde_json::json!(res))),
        Err(e) => Err(e.to_string()),
    }
}
```
</CodeGroup>
