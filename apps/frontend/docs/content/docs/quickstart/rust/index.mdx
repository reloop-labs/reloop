## Prerequisites

To get the most out of this guide, you'll need to:

* [Create an API key](/learn/api-keys)
* [Verify your domain](/learn/domain)
* Have Rust and Cargo installed

## 1. Install

Add `reloop` to your `Cargo.toml`:

<CodeGroup>
```toml Cargo.toml
[dependencies]
reloop = "0.1.0"
tokio = { version = "1", features = ["full"] }
```
</CodeGroup>

## 2. Usage

Create a `main.rs` file and add the following code:

<CodeGroup>
```rust main.rs
use reloop::{Client, SendEmailParams};

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let client = Client::new("re_123456789");

    let params = SendEmailParams {
        from: "Acme <onboarding@reloop.dev>".to_string(),
        to: vec!["delivered@reloop.dev".to_string()],
        subject: "Hello from Rust".to_string(),
        html: "<strong>It works!</strong>".to_string(),
        ..Default::default()
    };

    let response = client.emails.send(params).await?;
    println!("Email sent successfully: {}", response.id);

    Ok(())
}
```
</CodeGroup>
