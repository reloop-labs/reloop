## Prerequisites

To get the most out of this guide, you'll need to:

* [Create an API key](/learn/api-keys)
* [Verify your domain](/learn/domain)
* Have a Cloudflare account

## 1. Install

Install the Reloop Node.js SDK:

<CodeGroup>
  ```bash npm
  npm install reloop-email
  ```
  ```bash yarn
  yarn add reloop-email
  ```
  ```bash pnpm
  pnpm add reloop-email
  ```
  ```bash bun
  bun add reloop-email
  ```
</CodeGroup>

## 2. Set up Environment Variables

Add your Reloop API key to your `wrangler.toml` or using the Cloudflare Dashboard:

<CodeGroup>
```toml wrangler.toml
[vars]
RELOOP_API_KEY = "re_123456789"
```
</CodeGroup>

## 3. Usage

<CodeGroup>
```typescript src/index.ts
import Reloop from 'reloop-email';

export interface Env {
  RELOOP_API_KEY: string;
}

export default {
  async fetch(request: Request, env: Env): Promise<Response> {
    const reloop = ReloopEmail.client(env.RELOOP_API_KEY);

    const { data, error } = await reloop.emails.send({
      from: 'Acme <onboarding@reloop.dev>',
      to: ['delivered@reloop.dev'],
      subject: 'Hello from Cloudflare Workers',
      html: '<strong>It works!</strong>',
    });

    if (error) {
      return new Response(JSON.stringify({ error }), { status: 500 });
    }

    return new Response(JSON.stringify(data));
  },
};
```
</CodeGroup>
