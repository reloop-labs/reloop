## Prerequisites

To get the most out of this guide, you'll need to:

* [Create an API key](/learn/api-keys)
* [Verify your domain](/learn/domain)
* Have a Vercel account and a project

## 1. Install

Install the Reloop Node.js SDK:

<CodeGroup>
  ```bash npm
  npm install reloop-email
  ```
  ```bash yarn
  yarn add reloop-email
  ```
  ```bash pnpm
  pnpm add reloop-email
  ```
  ```bash bun
  bun add reloop-email
  ```
</CodeGroup>

## 2. Set up Environment Variables

Add your Reloop API key to your Vercel project's environment variables:

<CodeGroup>
```bash .env
RELOOP_API_KEY=re_123456789
```
</CodeGroup>

## 3. Usage

Create a new function in `api/send.ts`:

<CodeGroup>
```typescript api/send.ts
import Reloop from 'reloop-email';
import type { VercelRequest, VercelResponse } from '@vercel/node';

const reloop = ReloopEmail.client(process.env.RELOOP_API_KEY);

export default async (request: VercelRequest, response: VercelResponse) => {
  const { data, error } = await reloop.emails.send({
    from: 'Acme <onboarding@reloop.dev>',
    to: ['delivered@reloop.dev'],
    subject: 'Hello from Vercel Functions',
    html: '<strong>It works!</strong>',
  });

  if (error) {
    return response.status(500).json({ error });
  }

  return response.status(200).json(data);
};
```
</CodeGroup>
