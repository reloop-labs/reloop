## Prerequisites

To get the most out of this guide, you'll need to:

* [Create an API key](/learn/api-keys)
* [Verify your domain](/learn/domain)
* Have a Deno Deploy account

## 1. Set up Environment Variables

Add your Reloop API key to your Deno Deploy project settings:

<CodeGroup>
```bash
RELOOP_API_KEY=re_123456789
```
</CodeGroup>

## 2. Usage

You can import the Reloop SDK directly using the `npm:` specifier:

<CodeGroup>
```typescript main.ts
import Reloop from 'reloop-email';

Deno.serve(async (req) => {
  const reloop = ReloopEmail.client(Deno.env.get("RELOOP_API_KEY"));

  const { data, error } = await reloop.emails.send({
    from: 'Acme <onboarding@reloop.dev>',
    to: ['delivered@reloop.dev'],
    subject: 'Hello from Deno Deploy',
    html: '<strong>It works!</strong>',
  });

  if (error) {
    return new Response(JSON.stringify({ error }), { status: 500 });
  }

  return new Response(JSON.stringify(data));
});
```
</CodeGroup>
