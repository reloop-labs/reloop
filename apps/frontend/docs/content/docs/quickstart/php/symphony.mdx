## Prerequisites

To get the most out of this guide, you'll need to:

* [Create an API key](/learn/api-keys)
* [Verify your domain](/learn/domain)
* Have an existing Symfony project

## 1. Install

Install the Reloop PHP SDK:

```bash
composer require reloop/reloop-email
```

## 2. Configuration

Add your Reloop API key to your `.env` file:

```bash
RELOOP_API_KEY=re_123456789
```

## 3. Usage

Register the Reloop client as a service in your `services.yaml` and use it in your controllers:

```php
// src/Controller/EmailController.php
namespace App\Controller;

use Reloop\Reloop;
use Symfony\Bundle\FrameworkBundle\Controller\AbstractController;
use Symfony\Component\HttpFoundation\Response;
use Symfony\Component\Routing\Annotation\Route;

class EmailController extends AbstractController
{
    private $reloop;

    public function __construct(string $reloopApiKey)
    {
        $this->reloop = Reloop::client($reloopApiKey);
    }

    #[Route('/send-email', name: 'app_send_email')]
    public function send(): Response
    {
        $this->reloop->emails->send([
            'from' => 'Acme <onboarding@reloop.dev>',
            'to' => ['delivered@reloop.dev'],
            'subject' => 'Hello from Symfony',
            'html' => '<strong>It works with Symfony!</strong>',
        ]);

        return new Response('Email sent!');
    }
}
```
