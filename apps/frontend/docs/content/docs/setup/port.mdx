---
title: Port
description: Local ports for frontends, backend APIs, Docker infrastructure, and mail services.
---

All services bind to localhost when running locally. Use [https://local.reloop.sh](https://local.reloop.sh) for day-to-day development — Caddy routes traffic and keeps session cookies scoped correctly.

<Callout type="warn" title="Port conflicts">
  Before `bun docker:up`, free **80**, **443**, **5432**, **6379**, and ClickHouse **9000** / MinIO **9010**. Optional edge mail (`bun docker:up:edge`) also needs **25**, **465**, and **587**.
</Callout>

## Docker & Mail

| Service | Port | Notes |
| :--- | :--- | :--- |
| Caddy | `80`, `443` | Reverse proxy / TLS (core) |
| Mailpit | `8025` | Captured outbound mail UI (core) |
| SMTP (outbound) | `465`, `587`, `2025`, `2465`, `2587`, `8020` | KumoMTA edge — `bun docker:up:edge` |
| Inbound (MX) | `25`, `8030` | KumoMTA edge — `bun docker:up:edge` |
