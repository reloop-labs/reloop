title: Port
description: Local ports for frontends, backend APIs, Docker infrastructure, and mail services.
---

All services bind to localhost when running locally. Use [https://local.reloop.sh](https://local.reloop.sh) for day-to-day development — Caddy routes traffic and keeps session cookies scoped correctly.

<Callout type="warn" title="Port conflicts">
  Stop any local PostgreSQL (`5432`), Redis (`6379`), or web servers on `80`/`443` before running `bun docker:up`.
</Callout>

## Docker & Mail

| Service | Port | Notes |
| :--- | :--- | :--- |
| SMTP (outbound) | `587`, `2025`, `8020` | KumoMTA — HTTP health on `8020` |
