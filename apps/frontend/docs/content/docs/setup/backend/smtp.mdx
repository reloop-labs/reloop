## Service Overview

Outbound KumoMTA mail transfer agent — accepts submission from the [mail](/setup/backend/mail) service and delivers to destination MX servers (or Mailpit in local dev).

| Property | Value |
| :--- | :--- |
| **Directory** | `apps/backend/smtp` |
| **Docker Service** | `smtp` (container `reloop-smtp`) |
| **SMTP Ports** | `587`, `2025` (submission/STARTTLS) |
| **HTTP Port** | `8020` (KumoMTA console, host-mapped from container `8000`) |
| **Stack** | `KumoMTA` `Lua` |


<Callout type="info" title="Inbound vs Outbound">
  Port `25` inbound MX reception is handled by the [inbound](/setup/backend/inbound) service, not this outbound engine.
</Callout>


## Quick Start
<Callout
  icon="union"
  variant="info"
>
The SMTP engine starts with the full local Docker stack:
</Callout>
```bash
bun docker:up
```

Or start only the SMTP container from the `local/` directory:

```bash
cd local
docker compose up -d smtp reloop-mailpit
```


## Configuration

Container variables are defined in `local/docker-compose.yml`:

| Variable | Default Value | Description |
| :--- | :--- | :--- |
| `BASE_URL` | `https://local.reloop.sh` | Platform base domain |
| `NATS_URL` | `reloop-nats:4222` | Delivery event bus |
| `KUMOMTA_TRUSTED_HOSTS` | RFC1918 ranges | Trusted submission sources |
| `TRACKING_SECRET` | (dev default) | Tracking signature secret |


## Policy Files

Lua policies live in `apps/backend/smtp/`:

* **`init.lua`** — spool partitions, SMTP listeners, HTTP console
* **`policy/smtp.lua`** — ESMTP authentication and recipient validation
* **`policy/queue.lua`** — scheduling, backoff, and retry logic
* **`policy/webhooks.lua`** — delivery event HTTP callbacks


## Container Commands

All commands run from the **`local/`** directory:

| Command | Description |
| :--- | :--- |
| `docker compose up -d smtp` | Start the SMTP container |
| `docker logs -f reloop-smtp` | Stream container logs |
| `docker compose stop smtp` | Stop the container |


## Mailpit Sandbox

In local development, outbound mail is captured by **Mailpit** instead of real inboxes:

* Web UI: [http://localhost:8025](http://localhost:8025)
* Internal SMTP sink: port `1025` inside the Docker network


## Architecture

| Layer | Detail |
| :--- | :--- |
| **Submission** | Accepts outbound mail from the mail service on ports `587`/`2025`. |
| **Spool** | Persists messages to Docker volumes for crash-safe recovery. |
| **Policy** | Lua scripts govern throttling, DKIM signing, and routing rules. |
| **Delivery** | Routes to real MX servers in production, or Mailpit locally. |
