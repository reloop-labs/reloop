## Service Overview

Outbound event webhooks — subscription management, HMAC signing, delivery, and retries via BullMQ.

| Property | Value |
| :--- | :--- |
| **Directory** | `apps/backend/webhook` |
| **Port** | `8013` |
| **Local URL** | [https://local.reloop.sh/api/webhook](https://local.reloop.sh/api/webhook) |
| **Swagger UI** | [https://local.reloop.sh/api/webhook/openapi](https://local.reloop.sh/api/webhook/openapi) |
| **Stack** | `ElysiaJS` `PostgreSQL` `Redis` `NATS` `BullMQ` |


## Quick Start

<Callout icon="union" variant="info">
Run from the monorepo root:
</Callout>

```bash
bun be:webhook:dev
```

The service starts with hot reloading on port `8013`.


## Environment Configuration

Variables live in `apps/backend/webhook/.env`. Running `bun env:setup` from the root auto-populates this file.

```bash
PG_URL=postgresql://reloop:reloop123@localhost:5432/reloop
REDIS_URL=redis://:reloop123@localhost:6379
WEBHOOK_ENCRYPTION_KEY=your-64-char-hex-key
PORT=8013
BASE_URL="https://local.reloop.sh"
NATS_URL=nats://localhost:4222
NODE_ENV=development
```

`WEBHOOK_ENCRYPTION_KEY` encrypts stored webhook signing secrets. If unset, secrets are stored in plaintext (acceptable for local dev only).

### Reference Table

| Variable | Required | Default |
| :--- | :--- | :--- |
| `PG_URL` | **YES** | `postgresql://...` |
| `REDIS_URL` | **YES** | `redis://...` |
| `WEBHOOK_ENCRYPTION_KEY` | Prod only | Dev key in `.env.dev` — encrypts webhook secrets at rest |
| `PORT` | **YES** | `8013` |
| `BASE_URL` | **YES** | `https://local.reloop.sh` |
| `NATS_URL` | **YES** | `nats://localhost:4222` |

## Architecture

| Layer | Detail |
| :--- | :--- |
| **Event capture** | Subscribes to NATS subjects (`kumomta.event.*`, `tracking.*`). |
| **Delivery** | BullMQ workers sign payloads with `x-reloop-signature` and POST to subscriber URLs. |
| **Retries** | Failed deliveries retry with exponential backoff. |
| **Schema** | `webhook`, `webhook_delivery` in `packages/db/src/schema/webhook.ts`. |
