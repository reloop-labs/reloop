| Property | Value |
| :--- | :--- |

| **Port** | `8014` |

## Quick Start
<Callout
  icon="union"
  variant="info"
>
Run the following command from the root of the monorepo:
</Callout>
```bash
bun be:contacts:dev
```

The service starts with hot reloading on port `8014`.


## Environment Configuration

Variables live in `apps/backend/contacts/.env`. Running `bun env:setup` from the root auto-populates this file.

```bash
# Database & Cache Configurations
PG_URL=postgresql://reloop:reloop123@localhost:5432/reloop
REDIS_URL=redis://:reloop123@localhost:6379

# Server Gateway Configuration
PORT=8014
BASE_URL="https://local.reloop.sh"
NODE_ENV=development

# Event Bus Broker
NATS_URL=nats://localhost:4222
```

### `contact` Table

Stores general recipient email profiles, subscription status, and automatic suppression details.

| Column | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `id` | `text` | `con_{cuid}` | Primary Key |
| `email` | `varchar(255)` | — | Recipient email address |
| `status` | `contact_status` | `'subscribed'` | Active subscription state |
| `organizationId` | `text` | — | FK → `organization.id` |
| `userId` | `text` | — | FK → `user.id` |
| `firstName` | `varchar(255)` | `null` | Recipient given name |
| `lastName` | `varchar(255)` | `null` | Recipient family name |
| `suppressionReason` | `suppression_reason` | `null` | Populated automatically on hard bounces or spam flags |
| `suppressedAt` | `timestamp` | `null` | Timestamp of suppression action |

## Architecture

| Layer | Detail |
| :--- | :--- |
| **Audience Management** | Creates, updates, and groups contacts into static lists or dynamic query-based segments. |
| **Custom Properties** | Extensible schema attributes (custom properties and values) defined on a per-organization basis. |
| **Caching** | Redis is utilized to store segmentation cache and temporary list metadata. |
| **Events** | Lifecycle events (contact creation, deletion, opt-in/opt-out status changes) are published to NATS under `contacts.*`. |
| **DB Client** | Relational data is stored in PostgreSQL and accessed using `@reloop/db` with Drizzle ORM. |
