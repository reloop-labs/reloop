## Service Overview

Contact preference center and tracked link redirects for outbound email.

| Property | Value |
| :--- | :--- |
| **Directory** | `apps/frontend/links` |
| **Port** | `3005` |
| **Local URL (preferences)** | [https://local.reloop.sh/preferences](https://local.reloop.sh/preferences) |
| **Local URL (redirect)** | [https://local.reloop.sh/redirect](https://local.reloop.sh/redirect) |
| **Stack** | `Next.js` `React 19` `Tailwind CSS` |


## Quick Start

<Callout icon="union" variant="info">
Run from the monorepo root:
</Callout>

```bash
bun fe:links:dev
```

The app starts with Turbopack hot reloading on port `3005`.


## Routes

| Route | Purpose |
| :--- | :--- |
| `/preferences/[token]` | Manage subscription topics and unsubscribe |
| `/redirect/[token]` | Track clicks and redirect to destination URL |


## Development Commands

| Command | Description |
| :--- | :--- |
| `bun fe:links:dev` | Start dev server with Turbopack |
| `bun run --filter=links build` | Compile production bundle |
| `bun run --filter=links start` | Run production build |
| `bun run --filter=links lint` | Run ESLint checks |


## Architecture

| Layer | Detail |
| :--- | :--- |
| **[Mail](/setup/backend/mail)** | Injects `/redirect/[token]` links in outbound HTML. |
| **[Contacts](/setup/backend/contacts)** | Powers preference page data. |
| **Caddy** | Routes `/preferences*` and `/redirect*` to port `3005`. |
