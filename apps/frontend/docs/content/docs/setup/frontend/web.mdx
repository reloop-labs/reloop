## Service Overview

Public marketing site — landing pages, pricing, and product content.

| Property | Value |
| :--- | :--- |
| **Directory** | `apps/frontend/web` |
| **Port** | `3000` |
| **Local URL** | [https://local.reloop.sh](https://local.reloop.sh) |
| **Direct URL** | [http://localhost:3000](http://localhost:3000) |
| **Stack** | `Next.js` `React 19` `Tailwind CSS` |


## Quick Start

<Callout icon="union" variant="info">
Run from the monorepo root:
</Callout>

```bash
bun fe:web:dev
```

The app starts with Turbopack hot reloading on port `3000`.


## Environment Configuration

Optional variables in `apps/frontend/web/.env`:

```bash
NEXT_PUBLIC_WEB_URL="https://local.reloop.sh"
NEXT_PUBLIC_API_URL="https://local.reloop.sh/api"
```

### Reference Table

| Variable | Required | Default |
| :--- | :--- | :--- |
| `NEXT_PUBLIC_WEB_URL` | **YES** | `https://local.reloop.sh` |
| `NEXT_PUBLIC_API_URL` | **YES** | `https://local.reloop.sh/api` |


## Development Commands

| Command | Description |
| :--- | :--- |
| `bun fe:web:dev` | Start dev server with Turbopack |
| `bun run --filter=web build` | Compile production bundle |
| `bun run --filter=web start` | Run production build |
| `bun run --filter=web lint` | Run ESLint checks |
