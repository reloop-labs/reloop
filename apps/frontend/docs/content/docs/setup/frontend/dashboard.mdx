## Service Overview

Main workspace app — campaigns, contacts, templates, analytics, and settings.

| Property | Value |
| :--- | :--- |
| **Directory** | `apps/frontend/dashboard` |
| **Port** | `3001` |
| **Local URL** | [https://local.reloop.sh/dashboard](https://local.reloop.sh/dashboard) |
| **Direct URL** | [http://localhost:3001](http://localhost:3001) |
| **Stack** | `Next.js` `React 19` `Tailwind CSS` |


## Quick Start

<Callout icon="union" variant="info">
Run from the monorepo root (requires [auth](/setup/backend/auth) running):
</Callout>

```bash
bun fe:dashboard:dev
```

The app starts with Turbopack hot reloading on port `3001`.

<Callout type="warn" title="Use the unified domain">
  Open [https://local.reloop.sh/dashboard](https://local.reloop.sh/dashboard), not `localhost:3001`, so session cookies work with [auth](/setup/backend/auth).
</Callout>


## Environment Configuration

Variables in `apps/frontend/dashboard/.env`:

```bash
NEXT_PUBLIC_APP_URL="https://local.reloop.sh"
NEXT_PUBLIC_API_URL="https://local.reloop.sh/api"
NEXT_PUBLIC_WS_URL="wss://local.reloop.sh"
```

### Reference Table

| Variable | Required | Default |
| :--- | :--- | :--- |
| `NEXT_PUBLIC_APP_URL` | **YES** | `https://local.reloop.sh` |
| `NEXT_PUBLIC_API_URL` | **YES** | `https://local.reloop.sh/api` |
| `NEXT_PUBLIC_WS_URL` | **YES** | `wss://local.reloop.sh` |


## Development Commands

| Command | Description |
| :--- | :--- |
| `bun fe:dashboard:dev` | Start dev server with Turbopack |
| `bun run --filter=dashboard build` | Compile production bundle |
| `bun run --filter=dashboard start` | Run production build |
| `bun run --filter=dashboard lint` | Run ESLint checks |
