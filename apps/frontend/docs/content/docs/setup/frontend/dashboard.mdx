# User Dashboard Service

> Powers Reloop's main user-facing application. This Next.js application acts as the central interface where users configure campaigns, view analytics, manage audiences, design templates, and manage API keys and custom domains.

<Callout type="info" title="Prerequisite">
Make sure you've completed the [local setup guide](/setup) first (cloned the repo, installed Bun, and have Docker infrastructure running).
</Callout>

---

## Quick Start

```bash
# One command to get started
cd apps/frontend/dashboard && cp .env.example .env && bun i && bun dev
```

Open [http://localhost:3001](http://localhost:3001) or [https://local.reloop.sh/dashboard](https://local.reloop.sh/dashboard) 🎉

---

## Service Info

* **Location:** `/apps/frontend/dashboard`
* **Port:** `3001` (configurable in `package.json` with `--port=3001`)
* **Tech Stack:** Next.js (with Turbopack), React, TypeScript, Tailwind CSS, Lucide Icons, Recharts, Tiptap, Framer Motion
* **Part of Monorepo:** Yes (run with filters or inside service dir)

---

## Environment Setup

Create `.env` file inside `/apps/frontend/dashboard`:

```bash
# Base URL for better-auth and redirects
NEXT_PUBLIC_APP_URL="https://local.reloop.sh"

# API Service URL for data fetching
NEXT_PUBLIC_API_URL="https://local.reloop.sh/api"
```

| Variable | Required | Description |
| :--- | :--- | :--- |
| `NEXT_PUBLIC_APP_URL` | `YES` | Base URL for the dashboard, used in OAuth redirect URLs. |
| `NEXT_PUBLIC_API_URL` | `YES` | Base API gateway URL routing to the various microservices. |

## Development Commands

```bash
# Install dependencies
bun i

# Start dev server with hot reload
bun dev
# or from monorepo root
bun run fe:dashboard:dev
# or using turbo filter
bun run --filter=dashboard dev

# Build for production
bun run build
# or from monorepo root
bun run fe:dashboard:build

# Start production server locally
bun run start
# or from monorepo root
bun run fe:dashboard:start

# Lint and check formatting
bun run lint
```

## Troubleshooting

### Port Issues
**Port already in use?**
```bash
# Check what's using port 3001
lsof -i :3001

# Kill the process
kill -9 <PID>
```

### Authentication Issues
**Dashboard fails to log in or redirects incorrectly?**
1. Check that the `auth` service is running on port `8000` (proxied to `https://local.reloop.sh/api/auth`).
2. Verify `NEXT_PUBLIC_APP_URL` is set to `https://local.reloop.sh` or `http://localhost:3001` depending on whether you are using the proxy.
3. Verify your browser allows cookie storage for `local.reloop.sh`.
