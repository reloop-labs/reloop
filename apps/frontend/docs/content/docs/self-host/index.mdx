title: Introduction
description: Self-host Reloop on your own server. The production path is a one-command installer for Ubuntu and Debian.
---

Reloop can run on a server you control. The production path today is a single command on a fresh Ubuntu or Debian VPS. The installer uses Docker Compose, generates secrets, and prints the DNS records to add.

The VPS installer and a Coolify template are ready. Kubernetes manifests and the other platform templates are not.

If you do not already have a server, [Darkless](/docs/self-host/darkless) is Reloop's infrastructure partner and can provide the machine. You still run the same installer.

---

## Deployment options

- **VPS installer:** the supported production install. Ubuntu 22.04, Ubuntu 24.04, Debian 12, or Debian 13.
- **Darkless:** a VPS or dedicated server from Reloop's infrastructure partner, then the same installer.
- **Coolify:** a Docker Compose template on a Coolify server.
- **Other platforms:** Dokploy, Railway, and the rest of the cards below are coming soon.
