The `email.scheduled` event ID is reserved for when Reloop emits a distinct event for emails scheduled for later delivery.

**Status:** inactive — not available for new webhook subscriptions until the send pipeline wires it. Use `email.sent` for acceptance today.

## Planned `data` shape

```json
{
  "id": "whev_01h…",
  "type": "email.scheduled",
  "created_at": "2026-07-22T12:00:00.000Z",
  "data": {
    "email_id": "em_123456789",
    "from": "sender@example.com",
    "to": ["recipient@example.com"],
    "subject": "Hello World",
    "status": "scheduled"
  }
}
```
