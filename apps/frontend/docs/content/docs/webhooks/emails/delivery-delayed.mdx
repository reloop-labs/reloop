The `email.delivery-delayed` event is triggered when an email's status changes to **delivery-delayed**.

## Payload

```json
{
  "type": "email.delivery-delayed",
  "created_at": "2023-01-01T12:00:00Z",
  "data": {
    "email_id": "em_123456789",
    "from": "sender@example.com",
    "to": ["recipient@example.com"],
    "subject": "Hello World",
    "status": "delivery-delayed",
    "timestamp": "2023-01-01T12:00:00Z"
  }
}
```

## Handling this event

When your endpoint receives an `email.delivery-delayed` event, you might want to:

- Update the status in your internal database.
- Trigger an automated follow-up workflow.
- Log the event for analytics purposes.
- Notify relevant team members if the event indicates an issue (e.g., bounce or failure).
