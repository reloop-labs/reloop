The `domain.updated` event is triggered when a domain is **updated** in your account.

## Payload

```json
{
  "type": "domain.updated",
  "created_at": "2023-01-01T12:00:00Z",
  "data": {
    "domain_id": "dom_123456789",
    "name": "example.com",
    "status": "verified"
  }
}
```

## Handling this event

When your endpoint receives a `domain.updated` event, you might want to:

- Sync the domain status with your internal configuration.
- Trigger automated setup or cleanup tasks.
- Notify administrators about changes to the domain infrastructure.
