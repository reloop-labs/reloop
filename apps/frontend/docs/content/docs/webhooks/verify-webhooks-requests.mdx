To ensure that webhook requests are authentic and coming from Reloop, you should verify the signature included in the request headers. This prevents unauthorized requests from reaching your application logic.

## Using the SDK

The easiest way to verify webhooks is by using the official Reloop SDK. It provides a built-in method to validate the request signature and parse the payload.

```typescript
import { NextRequest, NextResponse } from 'next/server';
import { Reloop } from 'reloop';

const reloop = new Reloop(process.env.RELOOP_API_KEY);

export async function POST(req: NextRequest) {
  try {
    const payload = await req.text();
    const signature = req.headers.get('reloop-signature');

    // Throws an error if the webhook is invalid
    const event = reloop.webhooks.verify({
      payload,
      headers: {
        'reloop-signature': signature,
      },
      webhookSecret: process.env.RELOOP_WEBHOOK_SECRET,
    });

    // Handle the verified event
    console.log(event.type);
    
    return NextResponse.json({ received: true });
  } catch (err) {
    return new NextResponse('Invalid webhook signature', { status: 400 });
  }
}
```

## Using Svix

Reloop uses [Svix](https://www.svix.com/) to manage and sign webhook deliveries. You can use the `svix` library directly for verification in any language.

First, install the library:

```bash
npm install svix
```

Then, use it to verify the raw payload and headers:

```javascript
import { Webhook } from 'svix';

const secret = process.env.RELOOP_WEBHOOK_SECRET;

export async function POST(req, res) {
  const payload = await req.text();
  const headers = {
    'svix-id': req.headers['svix-id'],
    'svix-timestamp': req.headers['svix-timestamp'],
    'svix-signature': req.headers['svix-signature'],
  };

  const wh = new Webhook(secret);

  try {
    const verified = wh.verify(payload, headers);
    // Success! Handle the event
  } catch (err) {
    return res.status(400).send('Verification failed');
  }
}
```

## Why should I verify webhooks?

Verification is critical for security because it allows you to:
1. **Confirm Identity**: Ensure the request actually originated from Reloop.
2. **Prevent Tampering**: Verify that the payload hasn't been modified in transit.
3. **Avoid Replay Attacks**: Signatures include a timestamp to prevent old requests from being re-submitted.
