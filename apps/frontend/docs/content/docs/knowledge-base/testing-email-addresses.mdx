When testing your Reloop integration, use these special email addresses to simulate different scenarios without sending real emails.

## Test Addresses

| Address | Behavior |
|---------|----------|
| `delivered@reloop.dev` | Simulates a successful delivery |
| `bounced@reloop.dev` | Simulates a hard bounce |
| `complained@reloop.dev` | Simulates a spam complaint |

## Development Mode

When using Reloop in development:

- Emails sent from unverified domains are automatically sandboxed
- Use the `reloop.dev` test addresses above to verify your integration
- Check the [Reloop dashboard](https://app.reloop.dev/emails) to see sent emails and their status

<Warning>
Never use real customer email addresses for testing. Always use the test addresses above or your own addresses.
</Warning>
