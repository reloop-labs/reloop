## Configuration

In your `[...nextauth].ts` or `auth.ts` file, configure the Email provider:

```typescript
import NextAuth from "next-auth"
import EmailProvider from "next-auth/providers/email"

export default NextAuth({
  providers: [
    EmailProvider({
      server: {
        host: "smtp.reloop.sh",
        port: 587,
        auth: {
          user: "reloop",
          pass: process.env.RELOOP_API_KEY
        }
      },
      from: process.env.EMAIL_FROM
    }),
  ],
})
```

## Environment Variables

Ensure you have these set in your `.env.local`:

```bash
RELOOP_API_KEY=re_123456789
EMAIL_FROM=onboarding@reloop.dev
```
