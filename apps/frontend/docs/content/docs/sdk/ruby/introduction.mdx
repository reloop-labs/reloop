## Prerequisites

To get the most out of this guide, you'll need to:

* [Create an API key](/learn/api-keys)
* [Verify your domain](/learn/domain)
* Have Ruby 2.7 or later installed

## 1. Install

Add the Reloop gem to your Gemfile:

<CodeGroup>
```ruby Gemfile
gem 'reloop'
```
</CodeGroup>

And then run:

<CodeGroup>
```bash
bundle install
```
</CodeGroup>

## 2. Usage

Create a script named `main.rb` and add the following code:

<CodeGroup>
```ruby main.rb
require 'reloop'

reloop = Reloop::Client.new(api_key: 're_123456789')

params = {
  from: 'Acme <onboarding@reloop.dev>',
  to: ['delivered@reloop.dev'],
  subject: 'Hello from Ruby',
  html: '<strong>It works!</strong>'
}

begin
  response = reloop.emails.send(params)
  puts "Email sent successfully: #{response['id']}"
rescue StandardError => e
  puts "Error sending email: #{e.message}"
end
```
</CodeGroup>
