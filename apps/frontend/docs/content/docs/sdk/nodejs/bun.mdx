## Prerequisites

To get the most out of this guide, you'll need to:

* [Create an API key](/learn/api-keys)
* [Verify your domain](/learn/domain)
* Have Bun installed on your machine

## 1. Install

Install the Reloop Node.js SDK using Bun:

```bash
bun add @reloop/node
```

## 2. Usage

Use the native `Bun.serve` to send an email:

```typescript
import { Reloop } from '@reloop/node';

const reloop = new Reloop('re_123456789');

Bun.serve({
  async fetch(req) {
    if (req.method === 'POST') {
      const { data, error } = await reloop.emails.send({
        from: 'Acme <onboarding@reloop.dev>',
        to: ['delivered@reloop.dev'],
        subject: 'Hello from Bun',
        html: '<strong>It works with Bun!</strong>',
      });

      if (error) {
        return new Response(JSON.stringify({ error }), { status: 500 });
      }

      return new Response(JSON.stringify(data));
    }
    
    return new Response('Not Found', { status: 404 });
  },
  port: 3000,
});
```
