## Prerequisites

To get the most out of this guide, you'll need to:

* [Create an API key](/learn/api-keys)
* [Verify your domain](/learn/domain)
* Have an existing Astro project

## 1. Install

Install the Reloop Node.js SDK:

<CodeGroup>
  ```bash npm
  npm install @reloop/node
  ```
  ```bash yarn
  yarn add @reloop/node
  ```
  ```bash pnpm
  pnpm add @reloop/node
  ```
  ```bash bun
  bun add @reloop/node
  ```
</CodeGroup>

## 2. Usage

In Astro, you can send emails from API routes (endpoints) or directly in the frontmatter of your Astro components if you are using SSR.

### API Route

Create an endpoint in `src/pages/api/send.ts`:

<CodeGroup>
```typescript src/pages/api/send.ts
import type { APIRoute } from 'astro';
import { Reloop } from '@reloop/node';

const reloop = new Reloop(import.meta.env.RELOOP_API_KEY);

export const POST: APIRoute = async ({ request }) => {
  try {
    const { data, error } = await reloop.emails.send({
      from: 'Acme <onboarding@reloop.dev>',
      to: ['delivered@reloop.dev'],
      subject: 'Hello from Astro',
      html: '<strong>It works from Astro!</strong>',
    });

    if (error) {
      return new Response(JSON.stringify({ error }), { status: 500 });
    }

    return new Response(JSON.stringify(data));
  } catch (error) {
    return new Response(JSON.stringify({ error: 'Internal Server Error' }), { status: 500 });
  }
};
```
</CodeGroup>
