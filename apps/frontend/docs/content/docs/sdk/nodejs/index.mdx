## Prerequisites

To get the most out of this guide, you'll need to:

* [Create an API key](/learn/api-keys)
* [Verify your domain](/learn/domain)

## 1. Install

Install the Reloop Node.js SDK using your preferred package manager:

<CodeGroup>
  ```bash npm
  npm install @reloop/node
  ```
  ```bash yarn
  yarn add @reloop/node
  ```
  ```bash pnpm
  pnpm add @reloop/node
  ```
  ```bash bun
  bun add @reloop/node
  ```
</CodeGroup>

## 2. Send email using HTML

Create a file named `index.ts` (or `index.js`) and add the following code:

<CodeGroup>
```typescript index.ts
import { Reloop } from '@reloop/node';

const reloop = new Reloop('re_123456789');

(async function () {
  const { data, error } = await reloop.emails.send({
    from: 'Acme <onboarding@reloop.dev>',
    to: ['delivered@reloop.dev'],
    subject: 'Hello World',
    html: '<strong>It works!</strong>',
  });

  if (error) {
    return console.error({ error });
  }

  console.log({ data });
})();
```
</CodeGroup>

## 3. Try it yourself

Run the script to send your first email:

```bash
npx ts-node index.ts
```
