API keys connect your apps to Reloop. You can create and manage them in the **dashboard** or with **code** — both do the same job.

![API Keys list in the Reloop dashboard](/docs/images/docs/api-keys/list.png)

## Two ways, same keys

| Task | Dashboard | Code |
|------|-----------|------|
| **Create** | Click **Create API key** | `reloop.apiKey.create` / cURL |
| **Use** | Copy secret into your app | Send key on every request |
| **Manage** | Row menu (rotate, disable, delete) | Same actions via API |

Create with either platform. Use the secret in your app. Manage with either platform.

Open the UI any time: [API Keys](https://reloop.sh/dashboard/api-keys)

---

## Create

<Tabs>
  <Tab title="Dashboard">
    ![Create API Key modal](/docs/images/docs/api-keys/create-form.png)

    1. Go to [API Keys](https://reloop.sh/dashboard/api-keys)
    2. **Create API key**
    3. Enter a name (e.g. `Production Server`)
    4. **Create API Key**
    5. Copy the secret (or the **.env** tab), then **Done**

    ![API Key created — copy once](/docs/images/docs/api-keys/create-success.png)
  </Tab>
  <Tab title="Code">
    Use any existing key to create another.

    ```javascript
    import { Reloop } from "reloop-email";

    const reloop = new Reloop({ apiKey: process.env.RELOOP_API_KEY });

    const { apiKey, apiKeyError } = await reloop.apiKey.create({
      name: "Production Server",
    });
    if (apiKeyError) throw apiKeyError;

    console.log(apiKey.key); // only returned here
    ```

    ```bash
    curl -X POST https://reloop.sh/api/api-key/v1/ \
      -H "x-api-key: $RELOOP_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"name": "Production Server"}'
    ```
  </Tab>
</Tabs>

<Warning>
Copy the secret immediately. After create (and rotate), it is never shown again.
</Warning>

## Use

Store the secret, then send it on every request as `x-api-key`.

<Tabs>
  <Tab title="Dashboard → your app">
    After create, copy from the success modal (**API Key** or **.env**):

    ![Store the key as RELOOP_API_KEY](/docs/images/docs/api-keys/use-env.png)

    Put it in your environment, then call Reloop from your code (next tab).
  </Tab>
  <Tab title="Code">
    ```env
    RELOOP_API_KEY=rl_prod_YOUR_API_KEY
    ```

    ```bash
    curl https://reloop.sh/api/domain/v1/list \
      -H "x-api-key: $RELOOP_API_KEY"
    ```

    ```javascript
    import { Reloop } from "reloop-email";

    const reloop = new Reloop({ apiKey: process.env.RELOOP_API_KEY });
    ```
  </Tab>
</Tabs>

## Manage

Disable, rotate, rename, or delete — dashboard row menu or API.

![API key row actions](/docs/images/docs/api-keys/actions.png)

| Action | What happens |
|--------|----------------|
| **Disable / Enable** | Pause or restore access |
| **Rotate Key** | New secret, same key — copy once, update apps |
| **Delete API Key** | Gone for good (type the name to confirm) |
| **Edit** | Rename only |

<Tabs>
  <Tab title="Dashboard">
    1. Open [API Keys](https://reloop.sh/dashboard/api-keys)
    2. Row **···** menu (or open the key)
    3. Choose **Disable**, **Rotate Key**, **Delete API Key**, or **Edit**
    4. On rotate: copy the new secret and update every place that used the old one
  </Tab>
  <Tab title="Code">
    ```javascript
    import { Reloop } from "reloop-email";

    const reloop = new Reloop({ apiKey: process.env.RELOOP_API_KEY });
    const id = "key_123456789";

    await reloop.apiKey.update(id, { name: "CI Pipeline" });
    await reloop.apiKey.disable(id);
    await reloop.apiKey.enable(id);

    const { apiKey } = await reloop.apiKey.rotate(id); // apiKey.key once
    await reloop.apiKey.delete(id);
    ```

    ```bash
    curl -X POST https://reloop.sh/api/api-key/v1/disable/key_123456789 \
      -H "x-api-key: $RELOOP_API_KEY"

    curl -X POST https://reloop.sh/api/api-key/v1/rotate/key_123456789 \
      -H "x-api-key: $RELOOP_API_KEY"

    curl -X DELETE https://reloop.sh/api/api-key/v1/key_123456789 \
      -H "x-api-key: $RELOOP_API_KEY"
    ```
  </Tab>
</Tabs>

## Security

### Store

| Do | Don’t |
|----|--------|
| `RELOOP_API_KEY` in env / secrets | Commit keys to git |
| One key per app | Share one key everywhere |
| Clear names (`Production`, `CI`) | Leave keys unnamed |

### If a key leaks

1. **Disable** it (dashboard or code) — access stops now
2. **Rotate** or **create** a replacement
3. Update apps with the new secret
4. **Delete** the old key when nothing uses it

### Remember

- Secret is shown **once** (create / rotate)
- Later you only see a **prefix** in the list
- Reloop stores a hash, not the full key
