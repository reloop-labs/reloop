---
title: Properties
description: Custom string and number fields on contacts — desktop or code.
---

**Properties** are custom fields on a contact (`company`, `plan_tier`, …). Types: **String** or **Number**, with an optional default.

Open the UI: [Contacts → Properties](https://reloop.sh/dashboard/contacts/properties)

---

## Create

<Tabs>
  <Tab title="Desktop" icon="monitor">
    ![Create a contact property](/docs/images/docs/contacts/properties-list.png)

    1. Go to [Contacts → Properties](https://reloop.sh/dashboard/contacts/properties)
    2. **Add Property**
    3. Name (letters, numbers, underscores), type **String** or **Number**, optional default
    4. Save
  </Tab>
  <Tab title="Code" icon="code">
    <ContactsCodeSamples id="contacts.properties.create" />
  </Tab>
</Tabs>

## Delete

Deleting removes the schema. Contacts keep raw values, but the field is no longer managed globally.

<Tabs>
  <Tab title="Desktop" icon="monitor">
    ![Delete a contact property](/docs/images/docs/contacts/properties-list.png)

    1. Open [Contacts → Properties](https://reloop.sh/dashboard/contacts/properties)
    2. Row **···** → **Delete**
    3. Confirm
  </Tab>
