## What are contact properties?

**Properties** are custom fields on a contact (`company`, `plan_tier`, …). Types: **String** or **Number**, with an optional default used in templates when a contact has no value.

Open the UI: [Contacts → Properties](https://reloop.sh/dashboard/contacts/properties)

## FAQ

### What are contact properties in Reloop?

Custom fields on the contact schema — **String** or **Number** — with an optional default. Use them for personalization and filtering (for example `company` or `plan_tier`).

### What property types does Reloop support?

**String** (free-form text) and **Number** (integer or decimal), plus an optional fallback when a contact has no value.

### What happens when I delete a contact property?

Deleting removes the schema definition. Existing contacts keep raw key-value data, but the field is no longer managed globally.

### How do I name a contact property?

Use letters, numbers, and underscores only. Names must start with a letter or underscore. Spaces become underscores.
