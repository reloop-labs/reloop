Properties allow you to store additional information about your contacts. These can be used for personalization in emails or for advanced filtering and segmentation.

## Default Properties

Every contact in Reloop has certain default properties:
- `email`: The contact's email address.
- `created_at`: When the contact was first added.
- `updated_at`: When the contact was last modified.

## Custom Properties

You can define custom properties to suit your business needs. Examples include:
- `first_name`
- `last_name`
- `company_name`
- `plan_type` (e.g., Free, Pro, Enterprise)

## Using Properties in Emails

You can use variables to inject contact properties into your email templates:

```html
Hello {{ contact.first_name }},

Thank you for joining {{ contact.company_name }}!
```

## How to Manage Properties

### 1. View Available Properties
In your dashboard, navigate to the **Properties** section to view a list of all custom properties defined across your workspace.
![Properties List Placeholder](/images/docs/contacts/properties-list.png)

### 2. Define a New Property
Click **"Add Property"** to define a new schema key. You will need to specify a unique variable name (e.g., `favorite_color`) and its expected data type (Text, Number, Date, etc.).
![Create Property Placeholder](/images/docs/contacts/create-property.png)

### 3. Assigning Values to Contacts
Once a property is defined globally, you can assign an individual value to a contact through their detailed profile page, or programmatically via the API.
![Edit Contact Property Placeholder](/images/docs/contacts/edit-property.png)
