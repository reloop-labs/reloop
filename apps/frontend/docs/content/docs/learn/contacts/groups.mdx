---
title: Groups
description: Organize contacts into static lists for targeted sends and reporting.
---

**Groups** are named lists of contacts. Add members manually, via API, or during import. Select groups when sending broadcasts so only those contacts receive the message.

Groups are **static** — membership changes only when you add or remove someone. They are not dynamic query-based lists.

Related: [Contact records](/docs/learn/contacts/contacts) · [Channels](/docs/learn/contacts/channels)

<Callout type="info" title="Groups vs. channels">
  **Groups** = *who* receives a particular send (recipient list).
  **Channels** = *what type* of mail a contact agrees to receive (opt-in preferences).
</Callout>

## Group schema

| Field | Type | Description |
| --- | --- | --- |
| `id` | string | Unique ID (e.g. `grp_abc123`) |
| `name` | string | Display name (1–255 characters) |
| `createdAt` / `updatedAt` | string | Timestamps |

## When to use groups

| Use case | Example name |
| --- | --- |
| Product cohort | `Beta Testers`, `Enterprise Customers` |
| Lifecycle | `Trial Users`, `Paid Customers` |
| Content | `Newsletter`, `Webinar March 2026` |
| Internal | `Team`, `Advisors` |

## Dashboard

### Groups tab

**Path:** Dashboard → **Contacts** → **Groups**

Each row shows name and **member count**. Click to open detail.

### Create a group

1. Click **Create Group**.
2. Enter a clear **name**.
3. Save.

### Manage members

**From group detail:**

1. Open the group.
2. Browse members or search to add contacts.
3. Remove members individually.

**From contact detail:**

1. Open a [contact](/docs/learn/contacts/contacts).
2. Under **Groups**, add or remove memberships.

### Send to groups

When creating a **broadcast**, select one or more groups. Reloop deduplicates contacts in multiple selected groups.

## API reference summary

| Operation | Method | Endpoint |
| --- | --- | --- |
| Create | `POST` | `/api/contacts/v1/groups/create` |
| List | `GET` | `/api/contacts/v1/groups/list` |
| Get | `GET` | `/api/contacts/v1/groups/:group_id` |
| Update | `PATCH` | `/api/contacts/v1/groups/:group_id` |
| Delete | `DELETE` | `/api/contacts/v1/groups/:group_id` |
| List members | `GET` | `/api/contacts/v1/groups/:group_id/contacts` |
| Add member | `POST` | `/api/contacts/group/:group_id` |
| Remove member | `DELETE` | `/api/contacts/group/:group_id` |

## SDK examples

### Create a group

```typescript
const { response, error } = await reloop.contacts.createGroup({
  name: "Beta Testers",
});
if (error) throw error;
console.log(response.id, response.name);
```

### List groups

```typescript
const { response, error } = await reloop.contacts.listGroups({
  page: 1,
  limit: 50,
  search: "beta",
});
if (error) throw error;
```

### Add contact to group

By contact ID or email:

```typescript
const { error } = await reloop.contacts.groups.addContact("grp_123", {
  contact_id: "cont_456",
});
if (error) throw error;

// or
await reloop.contacts.groups.addContact("grp_123", {
  email: "user@example.com",
});
```

### Remove contact from group

```typescript
const { error } = await reloop.contacts.groups.removeContact("grp_123", {
  contact_id: "cont_456",
});
if (error) throw error;
```

### List contacts in a group

```typescript
const { response, error } = await reloop.contacts.groups.listContacts("grp_123", {
  page: 1,
  limit: 50,
  search: "acme",
});
if (error) throw error;
```

Alternative — filter the main contact list:

```typescript
const { response, error } = await reloop.contacts.list({
  groupId: "grp_123",
  page: 1,
  limit: 50,
});
```

### Assign groups when creating a contact

```typescript
const { response, error } = await reloop.contacts.create({
  email: "new@example.com",
  groupIds: ["grp_newsletter", "grp_beta"],
});
if (error) throw error;
```
