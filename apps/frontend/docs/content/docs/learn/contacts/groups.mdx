---
title: Groups
description: Segment contacts into lists for targeted sends — desktop or code.
---

**Groups** are lists you send to — VIP Customers, Beta Testers, New Registrants. Same contact, many groups.

Open the UI: [Contacts → Groups](https://reloop.sh/dashboard/contacts/groups)

---

## Create

<Tabs>
  <Tab title="Desktop" icon="monitor">
    ![Create a contact group](/docs/images/docs/contacts/groups-list.png)

    1. Go to [Contacts → Groups](https://reloop.sh/dashboard/contacts/groups)
    2. **Create Group**
    3. Enter a name (e.g. `VIP Customers`)
    4. Save
  </Tab>
  <Tab title="Code" icon="code">
    <ContactsCodeSamples id="contacts.groups.create" />
  </Tab>
</Tabs>

## Add members

<Tabs>
  <Tab title="Desktop" icon="monitor">
    ![Add contacts to a group](/docs/images/docs/contacts/groups-list.png)

    1. Open a group from [Groups](https://reloop.sh/dashboard/contacts/groups)
    2. **Add Contacts to Group**
    3. Search, select contacts (or Select All)
    4. **Add Contacts**
  </Tab>

<Tabs>
