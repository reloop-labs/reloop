Reloop **Contacts** is where you store everyone you email. Each person is a **contact** — a record keyed by email address with profile data, [properties](/docs/learn/contacts/properties), [group](/docs/learn/contacts/groups) memberships, [channel](/docs/learn/contacts/channels) subscriptions, and a full **email activity** timeline.

This section covers everything in the Contacts area of the dashboard, plus matching API and SDK examples.

## Dashboard layout

Open **Contacts** in the Reloop dashboard. Four tabs organize the workspace:

| Tab | Purpose |
| --- | --- |
| **Contacts** | Searchable list of all subscribers; add and import contacts |
| **Properties** | Define custom fields used across all contacts |
| **Groups** | Named collections of contacts for broadcasts and reporting |
| **Channels** | Communication categories (Marketing, Product Updates, etc.) |

Click any contact row to open the **contact detail page** — profile fields, properties, groups, channels, and **email activity** in one view.

## Typical workflows

### 1. Add a contact manually

1. Go to **Contacts** tab.
2. Click **Add Contact**.
3. Enter **email** (required), **first name**, **last name** (optional).
4. Assign **groups** and **channels** if needed.
5. Set **custom property** values.
6. Save.

### 2. Create a group and add members

1. Go to **Groups** tab → **Create Group**.
2. Open the group → add contacts by search.
3. Or add from a contact detail page under **Groups**.

See [Groups](/docs/learn/contacts/groups).

### 3. Personalize email content

1. Define properties under **Properties** tab (e.g. `first_name`, `plan_type`).
2. Set values on each contact (detail page or API).
3. Use merge variables in templates: `{{ contact.first_name }}`.

See [Properties](/docs/learn/contacts/properties).

### 4. Let contacts manage what they receive

1. Create **public** [channels](/docs/learn/contacts/channels) for each message type.
2. Add a **preference center** link to email footers.

See [Subscriptions](/docs/learn/contacts/subscriptions) — this is the hosted page where subscribers toggle channels without logging in.

### 5. Import a list (API today; CSV soon)

Bulk CSV import from the dashboard is **coming soon**. Today, import programmatically with the API — see [Migration guide](/docs/learn/contacts/migration-guide).

## Product docs + API / SDK

Each feature page follows the same structure:

1. **Concept** — what it is and when to use it
2. **Dashboard** — step-by-step UI instructions
3. **API & SDK** — copy-paste examples with typed `{ response, error }` results
4. **API reference link** — full schema on the generated reference pages

Install the Node.js SDK:

```bash
npm install reloop-email
```

<CodeGroup>
```typescript Node.js SDK
import Reloop from "reloop-email";

const reloop = new Reloop({ apiKey: process.env.RELOOP_API_KEY! });

const { response, error } = await reloop.contacts.create({
  email: "jane@example.com",
  firstName: "Jane",
  properties: { company_name: "Acme" },
  groupIds: ["grp_123"],
});

if (error) {
  console.error(error.status, error.message, error.body);
  return;
}

console.log(response.id, response.email);
```

```bash cURL
curl -X POST https://reloop.sh/api/contacts/create \
  -H "x-api-key: re_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{"email":"jane@example.com","firstName":"Jane"}'
```
</CodeGroup>

Every SDK method returns `{ response, error }`. Check `error` before using `response`. HTTP failures do not throw.

## Terminology

| Term | Meaning |
| --- | --- |
| **Contact** | One subscriber, identified by email |
| **Property** | Custom field on a contact (string or number) |
| **Group** | Static named list of contacts |
| **Channel** | Category of mail with its own opt-in / opt-out |
| **Subscription** | A contact's opt-in or opt-out for a specific channel |
| **Suppression** | Automatic block after hard bounce or spam complaint |

We use **Groups**, not "segments" or "audience," in Reloop Contacts.
