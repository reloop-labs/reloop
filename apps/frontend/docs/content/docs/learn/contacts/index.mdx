Every person you email is a **Contact**: one email, one record. Subscription status, [properties](/docs/learn/contacts/properties), [groups](/docs/learn/contacts/groups), and [channels](/docs/learn/contacts/channels) live on that record — desktop or code.

Open the UI any time: [Contacts](https://reloop.sh/dashboard/contacts)

---

## Add

<Tabs>
  <Tab title="Desktop" icon="monitor">
    ![Add Contact in the dashboard](/docs/images/docs/contacts/dashboard-tabs.png)

    1. Go to [Contacts](https://reloop.sh/dashboard/contacts)
    2. **Add Contact** (or `⌘/Ctrl+A`)
    3. Enter one or more emails — optional groups
    4. Save

## Edit

Change name, status, or properties — row menu or API.

| Action | What happens |
|--------|----------------|
| **Edit** | Update name or properties |
| **Subscribe / Unsubscribe** | Toggle list status |
| **View Details** | Full profile, groups, channels, activity |

Status is `subscribed`, `unsubscribed`, or `blocked` (often from deliverability).

<Tabs>
  <Tab title="Desktop" icon="monitor">
    ![Contact row actions](/docs/images/docs/contacts/list-view.png)

    1. Open [Contacts](https://reloop.sh/dashboard/contacts)
    2. Row **···** menu (or open the contact)
    3. Choose **Edit**, **Subscribe**, or **Unsubscribe**
  </Tab>
