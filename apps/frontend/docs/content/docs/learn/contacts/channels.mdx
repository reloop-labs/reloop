**Channels** are subscription topics (Product Updates, Newsletter, Alerts). Contacts opt in or out per channel instead of a global unsubscribe.

Open the UI: [Contacts → Channels](https://reloop.sh/dashboard/contacts/channels)

## Settings

| Setting | Options |
|---------|---------|
| **Default** | `opt_in` — enroll new contacts · `opt_out` — enroll manually |
| **Visibility** | `public` — preference center · `private` — dashboard only |
