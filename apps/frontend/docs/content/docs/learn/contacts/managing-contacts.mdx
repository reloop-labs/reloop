This page walks you through every way to create, retrieve, update, and remove contacts in Reloop—both from the dashboard and programmatically via the API.

---

## Add a Contact

You can add contacts to Reloop in three ways, depending on your workflow.

### Add via API

The most common method for production applications. When a user signs up, subscribes, or interacts with your app, create a contact in real time.

```javascript
import { Reloop } from "reloop-email";

const reloop = new Reloop({ apiKey: "rl_123456789" });

const { contact, contactError } = await reloop.contacts.create({
  email: "john.doe@example.com",
  firstName: "John",
  lastName: "Doe",
  status: "subscribed",
  properties: { company: "Reloop", role: "Developer" },
  groupIds: ["grp_123456789"],
  channels: [{ channelId: "chn_123456789", subscription: "opt_in" }],
});
if (contactError) throw contactError;
```

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `email` | `string` | ✅ | Contact email address |
| `firstName` | `string` | — | Contact first name |
| `lastName` | `string` | — | Contact last name |
| `status` | `"subscribed" \| "unsubscribed" \| "blocked"` | — | Subscription status (defaults to `subscribed`) |
| `properties` | `Record<string, string \| number>` | — | Custom key-value properties |
| `groupIds` | `string[]` | — | Group IDs to add the contact to |
| `channels` | `{ channelId, subscription }[]` | — | Channels to enroll the contact in |

### Add by uploading a CSV

If you're migrating from another platform or have an existing list, use the bulk import feature.

1. Navigate to **Contacts** in your Reloop dashboard.
2. Click the **Import** button to open the bulk import page.
3. Prepare your `.csv` file with at least an `email` column header.
4. Upload your file and review the column mappings.
5. Confirm the import. The system will process the file and populate your contact database.

### Add manually from the dashboard

For one-off additions, you can add a contact directly from the dashboard.

1. Navigate to **Contacts** in your Reloop dashboard.
2. Click the **Add Contact** button.
3. Enter the **Email Address** (required).
4. Optionally provide **First Name** and **Last Name**.
5. Select the initial **Subscription Status**.
6. Click **Save** to create the contact.

## View Contacts

### View from the dashboard

- **Search**: Use the search bar in the Contacts tab to find contacts by email address.
- **Filter**: Use status filters to narrow down contacts (e.g., only `subscribed` or `unsubscribed`).
- **Inspect**: Click any row to open the contact's detail view, which shows their metadata, properties, groups, and channels.

### Retrieve via API

Fetch a single contact by their ID:

```javascript
import { Reloop } from "reloop-email";

const reloop = new Reloop({ apiKey: "rl_123456789" });

const { contact, contactError } = await reloop.contacts.get("con_123456789");
if (contactError) throw contactError;
```

List contacts with pagination and filtering:

```javascript
const { contacts, contactError } = await reloop.contacts.list({
  page: 1,
  limit: 10,
  status: "subscribed",
});
if (contactError) throw contactError;
```

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `page` | `number` | — | Page number (defaults to `1`) |
| `limit` | `number` | — | Results per page, max 100 (defaults to `100`) |
| `search` | `string` | — | Search by email address |
| `status` | `"subscribed" \| "unsubscribed" \| "blocked"` | — | Filter by subscription status |

## Update a Contact

### Update from the dashboard

1. Click any contact in the Contacts list to open their detail view.
2. Click the **Edit** button.
3. Modify their name, status, or custom property values.
4. Save the changes.

### Update via API

```javascript
import { Reloop } from "reloop-email";

const reloop = new Reloop({ apiKey: "rl_123456789" });

const { contact, contactError } = await reloop.contacts.update("con_123456789", {
  firstName: "Janet",
  status: "unsubscribed",
});
if (contactError) throw contactError;
```

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `email` | `string` | — | Updated email address |
| `firstName` | `string` | — | Updated first name |
| `lastName` | `string` | — | Updated last name |
| `status` | `"subscribed" \| "unsubscribed" \| "blocked"` | — | Updated subscription status |
| `properties` | `Record<string, string \| number>` | — | Updated custom properties |

## Delete a Contact

### Delete from the dashboard

1. Locate the contact in the Contacts table.
2. Click the context menu (three dots) on the row.
3. Select **Delete**.
4. Confirm the deletion in the confirmation modal.

### Delete via API

```javascript
import { Reloop } from "reloop-email";

const reloop = new Reloop({ apiKey: "rl_123456789" });

const { contact, contactError } = await reloop.contacts.delete("con_123456789");
if (contactError) throw contactError;
```
