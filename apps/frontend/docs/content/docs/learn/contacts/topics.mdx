Topics represent the different types of communication you send. They give your contacts granular control over what they want to receive, which helps reduce overall unsubscribe rates.

## How Topics Work

Instead of a single "unsubscribe from all" option, topics allow contacts to choose their preferences:
- **Product Updates**: New features and improvements.
- **Security Alerts**: Critical information about account safety.
- **Marketing**: Promotions and special offers.

## Subscription Status

A contact's relationship with a topic can be:
- **Subscribed**: The contact will receive emails for this topic.
- **Unsubscribed**: The contact has opted out of this specific topic.

## Default Subscription

When you create a topic, you can set the default subscription behavior for new contacts:
- **Opt-in**: Contacts are subscribed by default.
- **Opt-out**: Contacts must explicitly subscribe to receive emails.
