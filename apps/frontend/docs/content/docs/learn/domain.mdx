Configure your sending identities to ensure the highest possible inbox delivery rates. Reloop **Domain** settings walk you through adding and verifying the required DNS credentials.

## Key capabilities

* **Custom sending domains**: Send mail from your own branding (e.g. `mg.yourdomain.com` or `reloop.yourdomain.com`).
* **DNS configuration guides**: Automated generation of SPF (`txt`), DKIM (`cname`), and DMARC (`txt`) requirements.
* **Custom MX and return-path**: Set up dedicated inbound MX records and custom return paths to boost sender authority.
* **Automatic propagation checker**: Verify DNS configuration directly within the dashboard.
