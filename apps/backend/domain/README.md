# Domain Service API

The **Domain Service** is a core backend component of the Reloop ecosystem responsible for managing custom domains, DNS verification, and email-related configurations (DKIM, MX, etc.).

## 🔗 Quick Links

- 📚 **Documentation**: [Developer Docs](https://reloop.sh/dev/domain-service)
- 🌐 **Production API**: [API Base](https://api.reloop.sh/api/domain)
- 📜 **OpenAPI Spec**: [OpenAPI](https://reloop.sh/api/domain/openapi)
