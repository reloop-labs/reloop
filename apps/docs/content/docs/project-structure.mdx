# Project Structure

This monorepo maintains clean separation between frontend applications, backend services, and reusable packages. The architecture follows modern best practices for scalable development with efficient dependency management and build optimization.

<Callout type="info">
  Want to understand the technologies powering this structure? Check out our **[Tech Stack](/tech-stack)** page for detailed technology choices and explanations.
</Callout>

## Apps

The `apps/` directory contains all deployable applications, each serving specific user-facing or internal functionality.

    - **Location**: `apps/web/`

    - **Assets**: Icons, manifests, and web app resources

  <Card icon={<Icon name="monitor" />} title="Main" href="/apps/main">

## Packages

The `packages/` directory contains shared libraries and utilities that can be consumed across multiple applications.

<Cards>
  <Card icon={<Icon name="palette" />} title="@repo/ui" href="/packages/ui">
    **Design System & Component Library** - Comprehensive UI component library with modern React patterns. Includes 50+ components ranging from basic inputs to complex data visualizations.

    - **Location**: `packages/ui/`
    - **Components**: Buttons, forms, tables, modals, navigation, data display
    - **Features**: Polymorphic components, accessibility built-in
    - **Utilities**: Custom hooks, helper functions, styling utilities
  </Card>

  <Card icon={<Icon name="database" />} title="@repo/db" href="/packages/db">
    **Database Layer** - Centralized database management with schema definitions and database utilities.

    - **Location**: `packages/db/`
    - **Schemas**: Auth, audience management, email configurations
    - **Features**: Type-safe queries, migrations, Docker setup
    - **Tools**: Database client, schema validation, development utilities
  </Card>

  <Card icon={<Icon name="key" />} title="@repo/auth" href="/packages/auth">
    **Authentication Package** - Shared authentication logic, configurations, and utilities for consistent auth across applications.

    - **Location**: `packages/auth/`
    - **Features**: Auth configuration, client/server utilities, CLI integration
    - **Integration**: Works seamlessly with database and UI packages
    - **Security**: Modern auth patterns and best practices
  </Card>
</Cards>

## Tools & Configuration

The `tools/` directory houses shared configuration and development utilities that ensure consistency across the monorepo.

<Cards>
  <Card icon={<Icon name="paintbrush" />} title="Tailwind Configuration" href="/tools/tailwind">
    **Shared Styling Setup** - Centralized Tailwind CSS configuration ensuring consistent design tokens and styling across all applications.

    - **Location**: `tools/tailwind/`
    - **Purpose**: Design system foundation
    - **Benefits**: Consistent theming, reduced duplication
  </Card>

  <Card icon={<Icon name="code" />} title="TypeScript Configuration" href="/tools/typescript">
    **Type Safety Foundation** - Multiple TypeScript configurations optimized for different environments and use cases.

    - **Location**: `tools/typescript/`
    - **Configs**: Base, Next.js, Vite, internal packages
    - **Benefits**: Consistent type checking, optimized builds
  </Card>
</Cards>
