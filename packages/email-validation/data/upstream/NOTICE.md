# Third-party data

The files in this directory are vendored verbatim from
[BillionVerify/disposable](https://github.com/BillionVerify/disposable) and are
regenerated by `bun run --filter=@reloop/email-validation refresh`. Do not edit
them by hand — the refresh script overwrites the directory wholesale. Reloop's
own additions live in `../local/`, which the script never touches.

| File | Contents |
|---|---|
| `domains.txt` | Exact disposable domains, one per line |
| `wildcards.txt` | Wildcard suffixes (`*.example.com`), matching the base domain and every subdomain |
| `exceptions.txt` | Upstream allowlist — overrides `domains.txt` |

Upstream aggregates nine community-maintained lists (MIT, BSD-3-Clause and CC0)
and refreshes hourly via GitHub Actions.
