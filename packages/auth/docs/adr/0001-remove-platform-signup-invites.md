# Remove platform Signup Invites

Platform Signup Invites (invite codes that gated account creation, peer invites, console admin minting, and related bus/email paths) never launched and are removed entirely — application code, APIs, UI, bus event, and the `signup_invite` table. Do not reintroduce without an explicit product decision. This is unrelated to **Organization Invitation** (team member invites into an existing organization), which remains product.
