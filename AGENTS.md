## Agent skills

### Issue tracker

Issues and PRDs live as GitHub issues on `reloop-labs/reloop`, managed via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles map to identically-named labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context monorepo — a root `CONTEXT-MAP.md` points at per-context `CONTEXT.md` files under `apps/*` and `packages/*`. See `docs/agents/domain.md`.
